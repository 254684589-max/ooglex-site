# 更新日志 · 打工 WORKING LIFE

## 1.1.0（2026-09-24）画质升级
向写实都市（洛杉矶式黄昏雾霭天际线）方向整体提升画面。仍然全部由代码程序化生成，没有引入外部美术素材或新依赖。

### 新增
- 程序贴图 `world/proc_tex.gd`：四种建筑立面（玻璃幕墙 / 办公石材带形窗 / 住宅 / 赛博深色）各一张颜色图 + 夜间灯光图，
  沥青、人行道地砖、路面法线、棕榈叶。启动时生成一次并缓存。
- 自定义天空着色器 `world/sky.gdshader`：天顶→地平线渐变、太阳光晕与日轮、程序云层（随时间飘动）、夜间星空。
- 城外远景：两圈贴图高楼（中央商务区在北边更高，带退台和航空障碍灯）+ 城郊低矮建筑 + 一圈远山。
- 棕榈树（人行道两侧与公园）、更圆润的阔叶树、路边停放的汽车。
- 地面交通 `world/street_traffic.gd`：汽车沿右侧车道行驶、跟车保持车距，玩家挡在车道上会刹车（纯视觉，不撞人）。

### 修改
- 建筑体块改为贴图立面：窗户、窗框、窗帘、阳台、夜间一格格亮起的灯光都在贴图里；高楼分 2～3 段退台，
  屋顶有女儿墙、空调机组、水箱、电梯机房、天线或尖顶。原来每层 4 个窗带方块的做法取消（几何体更少）。
- 光照：AgX 色调映射 + 对比度 / 饱和度调整；雾改为带太阳散射与大气透视（远处的楼和山被染成天空色）；
  重新调了白天、黄昏、夜晚、阴雨的天空 / 太阳 / 环境光配色；夜间窗户亮度与泛光阈值降低，避免整栋楼糊成白色。
- 道路与人行道使用沥青 / 地砖贴图，加实体路缘石；霓虹路缘灯带变细变暗；公园草地与步道换成更自然的颜色。
- 人物模型：胶囊形躯干与四肢、肩部、下颌 / 鼻子 / 耳朵 / 眉毛 / 嘴、两层头发、圆头鞋；
  同一关节下的零件合并成一个顶点色网格，每个人的绘制调用从约 27 次降到约 10 次。
- 树干、棕榈、停放车辆的碰撞放在单独的物理层（prop）：挡住玩家，但相机弹簧臂不会因为它们突然拉近。
- 相机远裁剪面 1000 → 1600 米（看得到远山）。
- 介绍页新增「黄昏航拍」「夜景」两张实机截图，其余截图按新画面重拍。

### 修复
- 介绍页「开始游戏」链接带构建号（`play/?v=<构建号>`，由 `tools/stamp_web_build.py` 自动更新），
  避免更新后浏览器 / CDN 仍用缓存的旧 `play/index.html` 加载旧版游戏。

### 性能
- 典型视角绘制调用 338～510（1.0.0 为 326～474），城市网格顶点约 50 万。天空参数每 0.2 秒更新一次，
  反射立方体贴图 64 像素且不画云和星星。
