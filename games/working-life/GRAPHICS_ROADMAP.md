# 画质工程路线图 · 打工 WORKING LIFE

目标参考：GTA V 洛杉矶黄昏远景（粉紫天空、层层雾霭、棕榈剪影、大片低层城区与路灯、地标高楼、远山）。
网页版无法原样达到（WebGL 2 兼容渲染器没有 SSAO / SSR / 体积雾 / GI，也没有手工美术资产），
目标是让同类远景镜头的**观感**尽量接近，并另做桌面高画质版。

## 所有者的决定（2026-09-24）
1. 风格：**写实方向**（逐步淡化赛博朋克霓虹，保留店铺招牌）。
2. 素材：**同意引入免费开源素材**（CC0 等允许商用的许可；每个素材记录来源与许可）。
3. 网页版首次加载：**可以接受 120 MB 以上**。
4. 平台：由开发决定 → **做桌面高画质版**（阶段 4），网页版继续作为主入口。

## 阶段
| 阶段 | 内容 | 状态 |
|---|---|---|

| 2b | 引入外部素材：真实照片材质（屋顶 / 墙面 / 沥青 / 混凝土）、棕榈与行道树模型、低层房屋 / 仓库、车辆 | **受阻**：本环境网络策略拦截素材站（见下） |
| 3 | 城市规模：城外低层城区与铁路场、立交，轮廓独特的地标高楼与塔吊；远景 LOD / 替身、MultiMesh 批量 | 待开始 |

| 5 | 性能收尾：纹理压缩、画质分档、真机帧率实测 | 待开始 |

## 阶段 2b 需要放行的域名
本开发环境的网络策略拦截了以下素材站（2026-09-24 实测）：`polyhaven.com`（含 `dl.polyhaven.org`、`api.polyhaven.com`）、
`ambientcg.com`、`kenney.nl`、`quaternius.com`、`opengameart.org`。在云端环境设置的 Network access 里放行后即可继续。
GitHub 上的公开仓库可以访问，但缺少写实风格、许可明确（CC0）的城市素材。

每个阶段单独提交、测试（`tools/run_tests.sh` 303 项 + 截图对比 + `tests/perf_stats.tscn`），经所有者同意后上线。
