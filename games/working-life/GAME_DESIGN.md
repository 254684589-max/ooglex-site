# 游戏设计 · 打工 WORKING LIFE 1.0

## 核心体验
从「活下去」到「选择自己的人生」。前两章是生存压力（钱、饭、床），第三到五章是职业成长，第六章起是财富与选择，
第七章让玩家挑一种人生作为结局；结局之后可以继续，把其余目标也完成。

## 数值骨架
- 时间：一天现实约 22 分钟；上班、上课、睡觉、乘车会快进。开局第 1 天 17:00（傍晚到站）。
- 属性（0~100）：饱腹清醒时约每小时 -6；体力清醒时缓慢下降，奔跑、上班、上课消耗；睡觉每小时恢复 13×住房系数。
  压力>60 起降低效率；饱腹<10 掉健康；健康归零住院（急诊 ¥800），体力归零原地昏睡 6 小时。
- 效率 = 1 − 压力超额 − 疲劳 − 生病 − 饥饿 + 好心情，范围 0.5~1.1，乘到小游戏评分上。
- 技能升级经验：80 + 40×当前等级（满级共 2,600）。课程 100 / 230 / 420 经验，每天限一门；书 60~180；上班 10~30。
- 工资：日薪下班付现金；月薪按 22 个班次折算、每周五晚发到银行卡。评分影响 ±15~20%，迟到 −10%，雨天工地补贴 ¥40。
- 绩效：每班 (评分−60)/4；升职 = 技能 + 本级出勤班次 + 绩效 + 声望 + 上司评价 ≥40；绩效 <25 降职，<12 或旷工 3 次解雇。
- 面试通过率 = 基础 + 答题 + 沟通 + 着装 + 住房体面度 + 声望 + 心情 − 压力 + 人脉内推（第一份体力活基本必过）。
- 住房：旅馆 ¥50/晚 → 合租 ¥800 → 公寓 ¥2,500 → 高级 ¥8,000 → 别墅 ¥30,000 /月（押一付一，欠租 7 天被请走）。
- 投资：五种资产，周期（繁荣 / 平稳 / 衰退，18~40 天）决定漂移，叠加随机波动与新闻冲击；手续费 0.1%；
  分红 / 票息按日进银行卡计作被动收入。
- 创业：管理 Lv.5 + ¥10 万；产能 = 员工 × 设备 × 运营 × 管理技能 × 当日管理会议；项目按产能推进，逾期只收 25%；
  成本 = 工资 + 租金 + 市场预算；账户透支 14 天破产；阶段 工作室 → 小公司 → 成长型 → 中型企业 → 集团。

## 主线（17 个任务）
第一章 活下来：第一天（旅馆、吃饭、人才市场、申请、面试）→ 落脚（睡一觉）
第二章 第一份工作：上班一次 → 挣 ¥800 并完成 3 班 → 找刘老师上一门课
第三章 真正的职业：电脑 / 沟通 Lv.1 → 月薪工作 → 租房
第四章 选择方向：电脑 / 金融 / 管理任一 Lv.3 → 3 位 NPC 关系 30
第五章 职业发展：升职一次 → 职位等级 3 + 声望 30
第六章 财富积累：存款 ¥5 万 → 投资或创业 → 净资产 ¥30 万
第七章 人生选择：达成任一人生目标 → 中央公园观景台回望 → 结局

## 结局
| 结局 | 条件 |
|---|---|
| 普通人生 | 有工作且出勤 ≥20 班 + 普通公寓及以上 + 现金与存款 ≥ ¥10 万 |
| 职业经理人 | 云途集团总监，或公司管理者路线副总裁 / CEO |
| 技术专家 | 电脑 Lv.10 + 星河科技 Tech Lead / CTO |
| 创业成功 | 公司达到「中型企业」（25 人 + 累计营收 ¥500 万） |
| 财务自由 | 净资产 ¥500 万 + 近 30 天被动收入折合每月 ¥2 万 |
