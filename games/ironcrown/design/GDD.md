# 铁冠之争 THE IRON CROWN · 游戏设计文档

> 路线图步骤 0.3 · 2026-09-27 · 状态：初稿，待所有者审阅
>
> 依据：`WORLD.md`、`STORY.md`。类型：**第一人称、剧情驱动的中世纪写实角色扮演游戏**（对标方向：《天国：拯救》的写实近战与对话、
> 《上古卷轴》的第一人称探索），但规模按「网页、单人开发 + Claude」收缩：少而精的手工区域，重对话与抉择，战斗简化。
> 标「默认」的数值是起点，垂直切片里调手感。

---

## 一、设计支柱

1. **你说的话有分量**：对话是主要玩法之一；检定、谎言、声望、旗标，让同一个任务有不同的解法和后果。
2. **近战要沉**：每一剑都消耗体力，被格挡会失衡；不能无脑连点。
3. **小而密的世界**：每个区域都是手工摆放的，走十步就有东西可看、可聊、可偷。
4. **氛围先于数值**：雾、夜、灯火、风声；宁可少一个系统，也要场景耐看。

## 二、核心循环

```
探索 → 交谈 / 打探线索 → 做出选择（说服 / 欺骗 / 战斗 / 潜行 / 花钱）
  → 后果（声望、旗标、战利品、人物生死） → 成长（技能随使用提升、装备） → 解锁新的区域与对话
```

一次游戏时长目标：序章 15–25 分钟；每章 1.5–3 小时（完成后）。

## 三、操作

| 动作 | 电脑 | 手机 / 平板 |
|---|---|---|
| 移动 | WASD | 左半屏虚拟摇杆（推到底 = 跑） |
| 视角 | 鼠标（点击画面后锁定指针，Esc 释放） | 右半屏拖动 |
| 冲刺 | Shift 按住 | 摇杆推到边缘 |
| 蹲下 / 潜行 | Ctrl 或 C（切换） | 按钮 |
| 跳 | 空格 | 按钮 |
| 交互（对话、开门、拾取、搜刮） | E | 屏幕中央出现提示时点「交互」按钮 |
| 攻击：轻击 / 重击 | 左键（或 F）点击 / 按住 0.35 秒以上松开 | 「攻」按钮点按 / 长按 |
| 格挡 | 右键（或 Q）按住 | 「挡」按钮按住 |
| 拔出 / 收起武器 | R | 按钮 |
| 背包 / 任务日志 / 角色 / 地图 | I / J / K / M | 右上角菜单 |
| 快速存档 / 读档 | F5 / F9 | 菜单 |

- 所有面板和对话都能用鼠标、键盘（方向键 + 回车）和触屏操作；打开面板与对话时游戏暂停并释放鼠标。
- 手机横屏为主；竖屏显示「请横过来」提示，但不阻止游玩。

## 五、角色成长

### 5.1 四项属性（开局按出身分配，升级时加点）

| 属性 | 影响 |
|---|---|
| 力量 | 近战伤害、负重上限、重击破防 |
| 敏捷 | 攻击与格挡速度、体力恢复、潜行 |
| 体魄 | 生命、体力上限、抗寒 |
| 机敏 | 对话检定（口才 / 威吓 / 洞察）加成、搜刮找到更多东西、商店价格 |

### 5.2 技能：用什么涨什么

| 技能 | 怎么涨 | 作用 |
|---|---|---|
| 剑术 | 用剑命中、格挡 | 伤害、连击段数（2 → 3）、完美格挡窗口 |
| 钝器 | 用锤 / 棍命中 | 破甲、击倒 |
| 格斗 | 徒手命中 | 徒手伤害；酒馆斗殴不致命 |
| 口才 | 说服、撒谎成功 | 口才检定 |
| 威吓 | 威吓成功 | 威吓检定 |
| 洞察 | 看穿谎言、找到线索 | 对话里显示「对方在说谎」的提示；更多调查选项 |
| 潜行 | 未被发现地接近 | 被察觉速度降低 |
| 生存 | 搜刮、在寒冷中行动 | 抗寒、搜刮收获 |

- 技能 0–100；每提升一定总量角色升一级，得 1 个属性点。
- 不做庞大的技能树；每个技能在 25 / 50 / 75 各解锁一个「专长」（例：剑术 25「连环」——轻击可连三段；剑术 50「反击」——完美格挡后的下一击必定重击。完整列表在 `data/progression.json`，2.7）。

### 5.3 对话检定

- 检定值 = 技能 + 机敏 × 2 + 情境修正（声望、已知情报、衣着、贿赂）。
- 选项上**直接显示成功把握**（2026-10-04 起写百分比「[口才检定 · 约 60%]」，所有者看不懂「把握较大」这类说法），不藏骰子；失败也会推进剧情（换一条更难的路），不存在卡死。
- 不允许读档刷检定：同一个检定的结果在进入对话时就已经确定（按存档种子）。

## 六、战斗

### 6.1 基本规则

- **生命**：受伤扣除，不会自动恢复；靠食物、绷带、休息恢复。
- **体力**：攻击、格挡、冲刺消耗，停止动作后自动恢复；体力耗尽时攻击变慢、格挡会被打破。
- **轻击**：快、伤害低、体力消耗小；可连 2 段（剑术 25 后 3 段）。
- **重击**：有 0.35 秒蓄力，伤害高，能打破对方格挡。
- **格挡**：按住时正面受到的伤害变成体力消耗；**完美格挡**（在对方命中前 0.2 秒内按下）不耗体力、让对方失衡 0.8 秒。
- **失衡**：被完美格挡、被重击破防、体力耗尽时进入失衡，这期间受到的伤害加倍。
- 不做《天国》那样的五向攻击：网页和手机上太难操作。攻击方向由武器动画自动决定。

### 6.2 敌人

| 敌人 | 出现 | 行为 |
|---|---|---|
| 醉汉 | 序章酒馆 | 徒手，动作慢，打倒后认输（不死） |
| 无旗者 · 棍手 | 序章 | 近战，冲上来猛攻，体力耗尽后后退 |
| 无旗者 · 剑手 | 序章 | 会格挡、会绕到侧面 |
| 无旗者 · 弓手 | 序章 | 保持距离射箭，被近身时逃跑 |
| 「灰手」奥弗 | 序章头目 | 重击多、会踢（破格挡），半血时喊手下包抄；可被说服退走 |
| 长眠者 | 第二章起 | 不攻击、不可杀死，只能用火驱散或推倒拖住；成群出现时是环境威胁 |

- AI 状态：巡逻 → 起疑（头顶「?」，1.5 秒内再看到你就发现）→ 警觉（「!」，呼叫附近同伙）→ 战斗 → 受重伤时逃跑或求饶。
- 同时攻击玩家的敌人最多 2 个，其余绕圈等待（避免被围殴得毫无还手之力，也降低 AI 开销）。
- 求饶的敌人可以放走（部分会带来后续的回报或报复）。

### 6.3 伤害公式（默认）

```
伤害 = 武器基础伤害 × (1 + 力量 × 0.03 + 技能 × 0.005) × 攻击类型系数（轻 1.0 / 重 1.8）
       × 失衡倍率（2.0 或 1.0） − 护甲减免
护甲减免 = 护甲值 × 0.5（下限：至少造成伤害的 20%）
```

### 6.4 军阵战斗（2026-10-04 所有者定 D8「中型战斗」；第一章起，路线图阶段 B）

在哪几章、打什么见 `STORY.md` 1.1；性能依据见 `TECH.md` 4.10。B.1（2026-10-04）已实现阵营、士兵挑对手、按目标分配的攻击令牌、友军砍不到、同屏名额排队，网页 `?test=3` 军阵试验场可以试；B.2（2026-10-04）已实现小队与三个命令；B.3（2026-10-05）已实现士气、溃逃、队长、援军与胜负；兵种在 B.4。

| 项目 | 规则 |
|---|---|
| 规模 | **同时活着、在打的士兵双方合计 ≤ 60**（含友军，不含玩家）。一场战斗可以分波入场；倒下、溃逃、求饶的人让出名额，后一波才进来 |
| 阵营 | 每个兵属于一方，同方的人不互相砍；玩家的剑也砍不到友军（手机上乱战时误伤太难避免）。同一家族内斗时用臂带颜色区分 |
| 士兵 AI | 在现有敌人 AI（6.2）上扩展：找最近的敌方目标（玩家也是目标之一），每个目标同时最多被 2 个人攻击，其余的人绕圈或换下一个目标；所以战场上是一对一、二对一的缠斗，而不是所有人挤成一团。玩家仍然同时最多被 2 个人攻击 |
| 兵种（首批） | 剑兵；剑盾兵（盾挡正面的轻击，重击破盾）；持棍的民兵（佃农，弱、容易溃逃）；队长（多血、会踢、半血喊包抄，规则同「灰手」奥弗）。**长枪兵与弓手**：免费动作库里没有长枪和弓的动作（`assets/SOURCES.md`），要么所有者再提供动作素材，要么用代码改骨骼姿势做简化版，B.4 再定 |
| 指挥 | 只指挥自己身边的小队（6–12 人），三个命令：**跟随我**（在你身后排成三人一排跟着走，只打离你 7 米以内的敌人）/ **原地坚守**（在你下令时站的地方前面 2 米排成一线，只打坚守点 5 米以内的敌人，打完回位）/ **冲锋**（自己找最近的敌人打，默认）。电脑数字键 1 / 2 / 3，手机点「令」展开三个按钮；小队的人头顶有金色 ◆，右上角写「◆ 小队 6 人：跟随我」（B.2 已实现） |
| 士气 | 每个兵有士气：附近的同伴倒下、被包抄、己方队长倒下时下降，己方占优时回升；低到一定程度就逃跑或跪地求饶（复用 6.2 的逃跑 / 求饶）。一方倒下与溃逃的人过半，这一方就输了。**击倒对方队长**是玩家左右战局的主要办法。<br>**B.3 初版数值**：剑兵 70、民兵 55、队长 100（各自最多再涨 20）；8 米内同伴倒下 / 求饶 / 逃跑 −10（民兵 −15，同伴是被吓跑的减半）；己方队长被打倒全队 −20、对面全队 +15；每秒看身边 8 米：敌多我少（不到三分之二）−3，占优（1.5 倍）或身边没敌人 +2，同时被两个人打 −3，你在 6 米内 +2；掉到 15 以下逃跑或求饶。倒下 / 求饶 / 逃跑超过总数（含排队和没到的援军）一半：剩下的全体溃逃、援军不来了、这一方输——你这边溃逃，你还站着也算输。右上角「战况」一行写两边人数、援军和士气（稳 / 动摇 / 快崩了） |
| 胜负与后果 | 胜负都写旗标、都推进剧情（`STORY.md` 1.1）；开战前自动存档，玩家倒下就读档（B.3 已实现：`Battle.result_flag` 写 `"won"` / `"lost"`，`main.start_battle()` 先存档再开打） |
| 援军 | 一场战斗可以分波：某一方开打若干秒后有一批人从指定的地方进场（同屏名额照旧管）；那一方先溃逃的话援军就不来了（B.3） |
| 搜刮 | 战后只有队长和有名字的人能搜；普通士兵倒下后不留搜刮点（物体太多，也不好玩） |
| 难度 | 沿用第十二节的三档；故事难度下己方士兵的士气更稳 |

**不做**（D8）：百人以上的会战、攻城器械、骑兵冲锋、指挥整支军队、战略地图。

## 七、对话、任务、声望

### 7.1 对话

- 数据驱动的对话树：每个节点 = 说话人、台词、选项列表；选项可以有条件（技能、属性、旗标、声望、持有物品）和效果（改旗标、改声望、给物品、开始 / 推进任务、开战）。
- 对话时镜头平滑转向说话人，背景轻微虚化；字幕始终显示。
- **条件不够的选项**（3.9，2026-10-04）：剧情条件（旗标、任务进度、声望）不满足的选项隐藏，不剧透；剧情条件满足、只差银币或物品的选项**灰色显示在原来的位置**，不编号、点不了，后面写「（需要：30 枚银币（身上 12 枚））」「（需要：雇佣信）」，让玩家知道还有别的路。
  会剧透的物品选项（例如还没找到墓室里的信时「把信递给他」）照旧隐藏（对话数据里写 `"locked": "hide"`）。
- 首发不配音（阶段 6 再议）。

### 7.2 任务

- 任务日志：主线 / 支线分页，每个任务显示当前目标与已知线索；目标可以有多个完成方式。
- 不做任务标记满地图飞：只在地图上标「大致区域」，靠线索和对话找人。设置里可以打开「精确标记」照顾休闲玩家。

### 7.3 声望

- 对五大家族 + 烽誓团 + 渡工行会 + 无旗者各有一个声望值，−100 到 +100，五档：敌视 / 冷淡 / 中立 / 友善 / 信任。
- 声望影响：商店价格、对话选项是否出现、守卫是否放行、后续章节人物的态度。
- 声望变化时屏幕角落提示「瓦伦家 · 声望上升」（文字 + 箭头符号，不只靠颜色）。

### 7.4 旗标

- 所有关键选择写成旗标存进存档（例：`prologue_edric = "handed_over" | "let_go" | "blackmail"`）。
- 旗标清单集中维护在 `data/flags.json`，每个旗标写明在哪里设置、在哪里读取，防止写了没人用。

## 八、物品与经济

| 类别 | 例子 | 说明 |
|---|---|---|
| 武器 | 短剑、长剑、单手锤、木棍 | 首发 6–8 种；有耐久，磨损后伤害下降，铁匠修理 |
| 护甲 | 头、身、手、腿四个部位 | 布 / 皮 / 锁甲 / 板甲（后期）；越重护甲越高、越吵（影响潜行） |
| 消耗品 | 面包、烈酒、绷带、火把 | 烈酒回体力但降低准头；火把驱散长眠者 |
| 任务物品 | 借据、信件、钥匙 | 不能丢弃 |
| 杂物 | 银勺、皮毛 | 卖钱 |

- 货币：银币。
- 负重：超过上限后不能冲刺。
- 偷窃：被人看见会被追、降声望；首发只做「拿起前提示这是别人的东西」+ 被看见的后果，不做复杂的犯罪系统。

## 九、世界与时间

- 手工区域，每章一个；区域之间用地图快速旅行（旅途中可能触发随机遭遇，阶段 4 以后）。
- 昼夜：序章固定在夜里（剧情需要）；之后的章节有昼夜循环，NPC 按作息移动（阶段 4 以后）。
- 天气：雾、小雪、大雪；寒冷值在户外缓慢上升，靠火堆、酒馆、厚衣服降低。序章只做雾和寒冷提示，不做冻伤惩罚。

## 十、存档

- 浏览器本地存档：3 个手动栏位 + 1 个自动存档 + 1 个快速存档（电脑 F8 快速存档、F9 快速读档；浏览器里 F5 是刷新页面）。
- 自动存档时机：进入新区域、完成任务目标、做出关键抉择之前。
- 存档内容：位置与朝向、属性与技能、背包与装备、任务进度、声望、旗标、已拾取 / 已搜刮 / 已死亡的对象、对话检定种子。
- 格式带版本号，读档时逐版本迁移；读档失败时退回上一份，不用空数据覆盖有效存档。

## 十一、界面

- 风格：羊皮纸 + 铁框，克制、不遮挡画面（见 `ART.md` 第五节）。
- HUD 只有：左下生命与体力两条细条、屏幕中央准星与交互提示、右上角提示消息；没有小地图（沉浸感），打开地图才看。
- 生命低时画面边缘变暗、心跳声（同时有文字提示「重伤」），不用满屏红色闪烁。

## 十二、无障碍

- 字幕常开，字号三档；对话框背景不透明度可调。
- 头部摆动、镜头震动可关；尊重系统「减少动态效果」。
