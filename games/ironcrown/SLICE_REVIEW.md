## 一、怎么玩

- 网址：`https://www.ooglex.com/games/ironcrown/play/`（3.8 已上线，包括开场和教学提示）。
- 电脑：键盘鼠标，点击画面开始；手机 / 平板：触屏（左半屏走路、右半屏转视角）。需要支持 WebGL 2 的浏览器，首次加载约 57 MB。
- 完整玩一遍约 15–25 分钟。想看另外两种结局，结束画面里点「从头再来」（存档不受影响）。
- 只想快速看某一处，可以用这些网址参数（截图和测试用的，会跳过开场）：

| 想看什么 | 网址后面加 |
|---|---|
| 酒馆 / 教堂墓园 / 桦林 / 渡口 | `?area=tavern` / `?area=churchyard` / `?area=birch` / `?area=ferry` |
| 酒馆里一进门就和醉汉打架 | `?area=tavern&brawl=1` |
| 直接看结束画面（三种回顾） | `?ending=deliver` / `?ending=release` / `?ending=extort` |
| 帧率基准（不要操作，约 20 秒出结果表，请截图） | `?perf=1` |

## 二、流程一览

1. **开场**：标题卡「序章 · 霜渡镇之夜」，点一下开始。钟敲三下，站在领主宅邸门口的你被身后的管家喊住：少爷埃德里克天黑后没回来，要你悄悄找回来。
2. **打探**（至少两条线索，顺序随意）：
   - **更夫**：少爷往渡口去了；南方人戴着双钥印戒。
   - **「倒钩鱼」酒馆**：老板娘玛蒂尔达可以付钱打听、用口才检定，或者替她和醉汉大桶徒手打一架；伐木工说桦林边有营火。
   - **星铁小教堂**：奥尔本修士借你墓园钥匙，墓室里有少爷没写完的信。
3. **镇外桦林**：无旗者的哨卡。拿武器战斗、格挡、体力都在这里教；从头目身上搜出盖着双钥印的雇佣信。
4. **渡口**：「灰手」奥弗堵着码头。可以付 30 银币、亮出雇佣信说服他、威吓，或者直接开打（他会踢，半血喊手下包抄）。之后塞拉斯和少爷说出借据的事。
5. **抉择**：借据背面压着王室的星铁冠印。三选一：**交出**（带他回去）、**放走**（坐船南下）、**勒索**（扣下借据，向塞拉斯要 120 银币）。
6. **尾声**：修士提着风灯赶来，认出那枚印，交给你一本烧焦的旧书——「去黑鹭堡，别让任何人看见」。结束画面「第一章 · 黑鹭堡　开发中」，按你的选择写这一夜的回顾。

| 方面 | 想听你的判断 |

| 画面氛围 | 雾、街灯、窗光、写实地面与墙，是否接近你最初想要的「雾夜小镇」气质？哪里最出戏？ |

## 四、已知限制（如实）

- **人物**：NPC 与敌人是占位胶囊；主角只有 CC0 底模（没头发、没衣服），换装在 A.2，需要你提供服装包。
- **声音**：只有开场的钟声；脚步、刀剑、环境声和音乐都没有（A.3）。
- **玩法**：弓手没做（敌人只有近战）；渡船上不去；没有同伴系统（选「交出」以后少爷不会跟着你走）；门的开关状态不存档。
- **剧情**：「放走」以后对维克托撒谎的口才检定、「瓦伦家知道了你勒索」的后果，都留到第一章。
- **美术**：白桦、马、渡船是代码搭的简单几何体；室内（酒馆、小教堂）比室外粗糙。
- **性能**：这里只有软件渲染的数字（没有显卡），真实设备的帧率要你实测。
