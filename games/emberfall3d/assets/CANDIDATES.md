# 素材候选台账（阶段 2.1）

> 2026-09-26 调研。只列许可清楚的来源。「能否访问」是在本云端开发环境里实测的结果（`curl` / `git`）。
> 真正用进游戏的素材另记 `SOURCES.md`（名称、作者、许可、链接、下载日期）。本表里的素材**都还没有进仓库**。

## 一、实测结论

- **被拦截**：polyhaven.com、api.polyhaven.com、dl.polyhaven.org、ambientcg.com、kenney.nl、quaternius.com、opengameart.org、sketchfab.com、fab.com、poly.pizza（连接被网络策略拒绝）。
- **能访问**：GitHub 上的公开仓库（`git clone` 与 raw.githubusercontent.com）。
- 所以现在唯一拿得到的正式 3D 素材是托管在 GitHub 上的 KayKit 素材包。

## 三、判断

1. **CC0 免费素材里基本没有能达到 D4 档次的角色与怪物**。能拿到的（KayKit）是 Q 版卡通；写实档次的角色几乎都要定制（AI 生成或请人做）。
2. **环境贴图**（地面、石墙、木头）用 Poly Haven / ambientCG 的 CC0 写实贴图 + 统一调色，是性价比最高的一步画质提升，但这两个站现在被拦截。
3. KayKit 可以当「比几何体好一点的占位」，但一旦用上，画面会被定成卡通风，和目标方向冲突。**是否采用由所有者决定，未决定前不进仓库。**
