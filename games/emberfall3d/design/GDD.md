## 一、设计支柱

1. **一刀一个反馈**：每次命中都有停顿、闪白、击退、声音和数字。打击感优先于数值深度。
2. **火种有代价**：最强的力量（心火）会在角色身上留下痕迹，剧情和台词都会记得。
3. **刷得明白**：装备好坏一眼能比，词缀少而有意义，传奇效果改变玩法而不是只加数值。
4. **网页上也流畅**：一次游戏 10–30 分钟就能完成一段目标；电脑鼠标和手机触屏都是一等公民。

## 二、核心循环

```
接任务（主城） → 野外 / 地下城清怪 → 拾取装备、升级、解锁技能
      ↑                                        ↓
  回城整理：换装、分解、找托比打造 ← 击败首领、推进剧情
```

- 主线约 **8–10 小时**：序章 45 分钟 + 6 章 × 60–90 分钟（网页版）。
- 通关后：无尽深渊（第十节）+ 更高难度重玩。

## 三、操作与镜头

| | 电脑 | 手机 / 平板 |
|---|---|---|
| 移动 | 左键点地面（按住持续）；可选 WASD | **左下虚拟摇杆**；也支持点地面移动（设置里切换） |
| 基础攻击 | 左键点敌人 | 右下大按钮（自动锁定最近敌人） |
| 技能 | `1`–`4` 向鼠标方向释放；右键 = 技能 1 | 基础攻击按钮周围 4 个技能按钮，按住拖动可调整方向 |
| 心火觉醒 | `R` | 技能环中央上方的按钮 |
| 药水 / 回城 | `Q` / `T` | 屏幕按钮 |
| 面板 | `I` 背包、`C` 角色、`K` 技能、`J` 日志、`Tab` 地图、`Esc` 菜单 | 右上角按钮 |

- 镜头：固定斜俯视（俯角约 55°），平滑跟随，可小范围缩放；遮挡角色的墙体和建筑自动半透明。
- 打开任何面板时游戏暂停（单机游戏，照顾手机玩家；V0.1 已验证可行）。

## 四、属性与战斗公式

### 4.1 属性

| 属性 | 作用 | 主属性职业 |
|---|---|---|
| 力量 | 烬卫伤害 +1%/点；护甲 +0.5/点 | 烬卫 |
| 灵巧 | 炉铳手伤害 +1%/点；暴击率 +0.02%/点 | 炉铳手 |
| 意志 | 寂术师伤害 +1%/点；资源上限 +0.2/点 | 寂术师 |
| 体能 | 生命 +3/点 | 全部 |

- 每级 **+3 自由属性点**（玩家手动分配，可在托比处付费重置）+ 主属性自动 +2、体能自动 +1。
- 等级上限 **50**（主线结束约 40 级）；满级后进入**火种位阶**：每级 1 点小幅加成（伤害 / 生命 / 抗性 / 金币掉落四选一），无上限但收益递减。

### 4.2 伤害

```
技能伤害 = 武器伤害 × 技能系数 × (1 + 主属性/100) × (1 + Σ伤害加成%) × 暴击(×暴击伤害) × 元素克制
受到伤害 = 原始伤害 × (1 - 护甲减伤) × (1 - 对应抗性)
护甲减伤 = 护甲 / (护甲 + 40 + 18 × 攻击者等级)，上限 75%（沿用 V0.1）
抗性减伤 = 抗性 / (抗性 + 5 × 攻击者等级)，上限 70%
```

- 基础暴击率 5%，暴击伤害 +50%。
- **伤害类型**：物理、火（燃）、冰（寂）、毒（沼泽 / 巫术）、虚（焚天者与寒寂的高阶攻击，无对应抗性，只能靠护甲和减伤）。
- **状态**：燃烧（持续伤害）、冰缓（减速 50%）→ 冰冻（叠满 3 层定身 1.5 秒）、中毒（持续伤害，可叠加）、静默（敌人无法施法）、眩晕、击退。首领对控制有递减免疫。

### 4.3 打击感规格（给阶段 1.4 用）

- 命中停顿：普通 40 ms，暴击 80 ms，首领阶段转换 200 ms。
- 受击闪白 0.1 秒；小怪击退 0.3–0.6 米；死亡时按伤害类型播放不同效果（燃烧成灰、冻碎、溶解）。
- 伤害数字：普通白、暴击金色放大、元素按颜色；可在设置里关闭。
- 屏幕震动与闪光都可在设置里关闭（无障碍）。

## 五、三个职业

每个职业：**1 个基础攻击 + 4 个技能栏 + 1 个心火觉醒**。每职业首发 **12 个技能**，玩家从中选 4 个装配（可随时在非战斗状态更换）。
每个技能在 10 级、25 级各解锁一次**分支强化**（二选一，可随时切换）。另有一张**天赋盘**：3 条分支 × 约 15 个节点，每级 1 点。

### 5.1 烬卫（近战 · 力量 · 资源「誓火」）

- **誓火**：命中敌人获得，上限 100，脱战缓慢衰减。基础攻击生成，技能消耗。
- 定位：前排、高护甲、贴身范围伤害、位移突进。可用巨剑（高伤害）或剑盾（高防御）。
- 天赋盘三分支：**誓甲**（防御、格挡、反伤）/ **焚锋**（火焰伤害、燃烧）/ **断誓**（暴击、低血量增伤）。

| 技能 | 类型 | 效果 |
|---|---|---|
| 断誓斩 | 基础 | 挥砍，生成 12 誓火 |
| 盾焰冲锋 | 位移 | 向前冲锋，撞飞沿途敌人 |
| 焚地践踏 | 范围 | 重踏地面，眩晕周围敌人并留下燃烧地面 |
| 誓链拖拽 | 控制 | 甩出锁链把一个或一排敌人拉到身前 |
| 烬环斩 | 范围 | 持续回旋斩，移动中可施放 |
| 灰甲 | 防御 | 数秒内受到伤害降低 40%，受击回复誓火 |
| 燃血战吼 | 强化 | 提升自身攻速与移速，燃烧附近敌人 |
| 守誓之壁 | 防御 | 竖起火焰屏障，挡住远程弹道 |
| 炉心重击 | 单体 | 蓄力重劈，对首领额外伤害 |
| 余火印记 | 减益 | 标记敌人，标记目标受到伤害提高，死亡时爆炸 |
| 陨烬跃击 | 位移 | 跃向目标地点，落地造成范围火焰伤害 |
| 七誓回响 | 被动型主动 | 召唤七守誓者的残影各斩一次（剧情相关，第 5 章解锁） |

### 5.2 炉铳手（远程 · 灵巧 · 资源「热度」）

- **热度**：射击会**增加**热度（与其他职业相反）。热度越高伤害越高，满 100 会**过热**锁枪 2 秒；排气技能把热度转成爆发。管理热度是核心玩法。
- 定位：远程持续输出、机关（炮台、飞轮）、击退与走位。武器：炉铳（单手 + 副手机关 / 双手重炮）。
- 天赋盘三分支：**过载**（高热度增益）/ **机巧**（炮台、飞轮）/ **爆破**（范围、击退）。

| 技能 | 类型 | 效果 |
|---|---|---|
| 连发 | 基础 | 快速点射，热度 +6 |
| 散弹轰击 | 范围 | 扇形霰弹，近距离伤害更高 |
| 穿甲弹 | 单体 | 贯穿一排敌人，无视部分护甲 |
| 烬械炮台 | 召唤 | 放置自动炮台，持续 12 秒 |
| 蒸汽喷射 | 位移 / 控制 | 向后喷射蒸汽，自己后跃、前方敌人击退，热度 -30 |
| 焚油罐 | 范围 | 投掷燃烧罐，留下火海 |
| 钩索 | 位移 | 钩住地形或敌人把自己拉过去 |
| 过载核心 | 强化 | 数秒内热度不会过热，热度增益翻倍 |
| 排气爆轰 | 范围 | 把当前全部热度转化为一次环形爆炸 |
| 烬械飞轮 | 召唤 | 放出环绕自身的飞轮，切割靠近的敌人 |
| 追踪弹幕 | 范围 | 发射多枚自动追踪的小型火箭 |
| 炉铳全功率 | 引导 | 原地引导，发射持续的火焰光束 |

### 5.3 寂术师（法师 · 意志 · 资源「静」）

- **静**：不施法时快速恢复；施法消耗。**冰缓 / 冰冻 / 静默敌人会返还静**。另有少量「燃」系技能，释放后消耗敌人身上的冰缓层数造成爆发（冷热互换）。
- 定位：控场、范围伤害、召唤空壳仆从；脆皮，需要走位。武器：法杖（双手）或短杖 + 寂典（副手）。
- 天赋盘三分支：**冻结**（控制、碎冰）/ **抹除**（单体爆发、处决）/ **空壳**（召唤、牺牲）。

| 技能 | 类型 | 效果 |
|---|---|---|
| 霜针 | 基础 | 发射冰针，叠加冰缓 |
| 寂冰棱 | 单体 | 大型冰棱，命中冰冻目标时碎裂溅射 |
| 静默领域 | 控制 | 地面领域：减速、静默其中的敌人 |
| 冻结之触 | 控制 | 近身冻结一个锥形范围 |
| 抹除 | 单体 | 对生命越低的敌人伤害越高，击杀返还全部静 |
| 霜渊裂隙 | 控制 | 在目标点撕开裂隙，把周围敌人吸向中心 |
| 空壳仆从 | 召唤 | 召唤 2 个空壳替你战斗（上限随天赋提高） |
| 寒寂护甲 | 防御 | 护盾，近战攻击者被冰缓 |
| 残响 | 强化 | 下一个技能会在 1 秒后自动再释放一次 |
| 冻河 | 范围 | 一条直线冰道，冻结经过的敌人 |
| 逆燃 | 范围 | 引爆范围内敌人身上的冰缓层数，造成火焰伤害 |
| 长夜降临 | 引导 | 引导期间周围持续降下冰雹，越久范围越大 |

### 5.4 心火觉醒（全职业共通的招牌系统）

- 战斗中造成和承受伤害会积累**心火**（0–100）。满了可按 `R` 发动**觉醒**：15 秒内厄鲁斯的力量接管身体，外观燃起灰烬，所有技能强化、冷却大幅缩短。三个职业的觉醒效果不同（烬卫：灰烬巨人；炉铳手：火种全功率；寂术师：冰与火共存）。
- 每次觉醒在角色身上留下 1 点**灼痕**。灼痕**不影响战斗数值**，只影响剧情呈现：
  - 灼痕达到阈值时，日志里的某段往事会被划掉（「遗忘」演出），厄鲁斯对话的语气变得更亲近或更强势，结局画面中主角的形象会变化。
  - 茉恩的「寂」之石可以封存一段记忆，使它不被划掉（每章 1 次）。
- 这样处理「遗忘」：**只做叙事演出 + 轻系统（日志划掉、台词变化），不锁任何内容、不惩罚战斗**，避免玩家为了剧情不敢用最爽的技能。

## 六、装备

### 6.1 装备栏（10 格）

武器、副手、头盔、胸甲、手套、腰带、护腿、靴子、护符、戒指 ×2。（双手武器占用副手格。）

### 6.2 品质

| 品质 | 颜色 | 词缀数 | 说明 |
|---|---|---|---|
| 普通 | 白 | 0 | 只有基础属性 |
| 魔法 | 蓝 | 1–2 | |
| 稀有 | 金 | 3–5 | 随机名字（沿用 V0.1 的「前缀 + 后缀」命名法） |
| 传奇 | 橙 | 3–4 + 1 条**传奇效果** | 传奇效果改变技能行为，例如「烬环斩会拉拢敌人」「炮台改为发射冰弹」 |
| 烬铸 | 红 | 由玩家在托比处打造 | 可指定 1 条词缀，其余随机；材料来自分解 |

- 首发规模：约 40 种基础装备、60 件传奇（每职业 15 件 + 通用 15 件）。套装留到阶段 8。
- 物品等级 = 掉落区域等级；需求等级 = 物品等级 × 0.6（沿用 V0.1）。

### 6.3 词缀（在 V0.1 的 16 种基础上扩充）

| 类别 | 词缀 |
|---|---|
| 属性 | 力量、灵巧、意志、体能、全属性 |
| 生存 | 生命、生命百分比、每秒回复、护甲、护甲百分比、全抗性、单项抗性、生命偷取、击杀回复 |
| 输出 | 伤害百分比、元素伤害百分比（火 / 冰 / 毒）、攻击速度、暴击率、暴击伤害、对首领伤害、对精英伤害 |
| 资源 | 资源上限、资源回复、技能冷却缩减、心火积累速度 |
| 功能 | 移动速度、照明范围（地牢光照）、金币掉落、魔法物品掉率、拾取范围 |
| 技能 | 某个技能的伤害 +%（按职业限定，只出现在对应职业的装备上） |

- 同一装备不出现重复类别；武器、首饰、护具各有可出词缀池（沿用 V0.1 的 `s` 限定写法）。

### 6.4 打造与分解（托比的工坊，第 2 章解锁）

- 分解装备得到**余烬碎屑**（按品质分三级）。
- **重铸**：花碎屑和金币，重新随机装备上的 1 条词缀（同一装备只能锁定重铸同一条）。
- **烬铸**：用高级碎屑打造指定部位的烬铸装备。
- **镶嵌**：宝石系统留到阶段 8，本文件不展开。

## 七、敌人

### 7.1 规模

- 每章 6–8 种普通怪（含 1–2 种沿用或变体），首发合计约 **45 种**；另有 14 个首领（`STORY.md` 第五节）。
- 每种怪只做一种清楚的行为：冲锋、远程、召唤、自爆、护盾、治疗、钻地……同屏的组合产生变化。

### 7.2 精英词缀（沿用 V0.1 的 5 种并扩充到 12 种）

迅捷、石肤、狂怒、嗜血、焚烧（死亡爆炸）、冰封（攻击冰缓）、瘟疫（留下毒池）、护盾（周期性无敌护盾）、传送、召唤（召唤小怪）、链接（两只共享生命）、静默（附近玩家技能冷却变慢）。
精英：名字蓝色，2 条词缀，带 2–4 只随从；首领随从精英：名字金色，3 条词缀。

### 7.3 首领设计规则

- 每个首领 2–3 个阶段，每阶段至少 1 个**只看画面就能躲**的招式（地面预警圈、蓄力动作、声音提示）；手机上也看得清。
- 阶段转换有 0.5–1 秒无敌演出，给玩家喘息。
- 首领战时长目标：适配等级下 2–4 分钟。
- 首领必掉：1 件传奇概率 30%（首次击杀 100%）+ 2 件稀有。

## 八、难度

| 难度 | 解锁 | 怪物生命 / 伤害 | 掉落 |
|---|---|---|---|
| 余火 | 默认 | ×1 | 基准 |
| 烈焰 | 通关一次 | ×2.5 / ×1.8 | 传奇掉率 ×2，物品等级 +10 |
| 焚世 | 烈焰通关 | ×6 / ×3 | 传奇掉率 ×4，物品等级 +20，精英 3 条词缀 |

- 难度名称刻意避开暗黑系列的难度名。
- 余火难度下死亡只在最近的检查点复活，不掉装备、不掉经验，损失少量金币（沿用 V0.1 的 10%）。

## 九、任务、对话与信任

- **主线任务**：每章 4–6 个，按 `STORY.md` 排序；地图上有明确指引，不让玩家迷路。
- **支线任务**：每章 3–4 个，奖励装备与世界观碎片；可完全跳过。
- **对话**：人物立绘（2D）+ 文本 + 2–4 个选项；关键选项旁显示人物头像提示「伊莲会记住这件事」。
- **伊莲信任度**（隐藏数值，0–10，起始 5），决定第 5 章伊莲的选择（`STORY.md`）：

| 章 | 事件 | 影响 |
|---|---|---|
| 序章 | 如实告诉伊莲余烬之心钻进了手里 / 隐瞒 | +1 / -1 |
| 1 | 用「寂」之石封存的记忆是「伊莲为你疗伤」那一段 | +1 |
| 2 | 先救矿工 / 先追巴拉克 | +1 / 0 |
| 3 | 把壁画的真相写信告诉伊莲 / 暂时不说 | +1 / -1 |
| 4 | 赫尔嘉战死后回烬原见伊莲一面（可选任务） | +1 |
| 各章 | 灼痕达到阈值时伊莲察觉到你的变化，你选择安抚或回避 | ±1 |

- 信任 ≥ 6：高信任分支；≤ 5：低信任分支。两种分支伊莲都活着。

## 十、无尽深渊（通关后）

- 入口在炉心。每层随机生成（沿用 V0.1 的房间 + 走廊生成思路，改为 3D 模块拼接），每 5 层一个随机首领。
- 每层随机 1–3 个**深渊印记**（例：怪物更快、火焰伤害 +50%、黑暗 —— 照明范围减半），印记越多奖励越高。
- 无计时（区别于常见的限时秘境）；进度按「最深层数」记录，后期可接排行榜（阶段 8，需审批 Cloudflare D1）。

## 十一、经济

- 货币：**金币**（买卖、重铸、重置属性）、**余烬碎屑**（打造）。
- 商人：铁匠（装备）、药剂师（药水、回城卷轴）、托比（打造，第 2 章起）；每次回城刷新货物。
- 药水：生命药水有 3 次充能，检查点和回城时回满，有短冷却（避免囤药）；回城卷轴无限使用，引导 3 秒，受击打断。
- **没有任何付费内容**（网页免费游戏，不做内购、不做抽卡）。

## 十二、存档

- 本地存档（localStorage / IndexedDB），3 个角色栏位；自动存档：进出区域、升级、获得传奇、每 60 秒。
- 存档带版本号，读档时做迁移；存档损坏时保留上一份有效存档（与网站「不用空数据覆盖有效数据」的规则一致）。
- 云存档留到阶段 8，需所有者另行审批。

## 十三、无障碍与设置

- 画质分档（低 / 中 / 高）、帧率上限、分辨率缩放。
- 关闭屏幕震动、闪光、伤害数字；色弱模式（掉落物与敌我标识不只靠颜色区分，另加图标 / 形状）。
- 字体大小两档；所有文字中文优先，关键术语可附英文。
- 尊重系统的「减少动态效果」设置。
