## 一、结构总览

- **序章 + 6 章 + 终局选择**，每章对应 `WORLD.md` 的一个区域。
- 每章的制作规模按「网页版约 60–90 分钟主线」规划：1 个主城 / 营地、2–3 个野外区域、1–2 个地下城、2 个首领（章中首领 + 章末首领）、4–6 个主线任务、1 段引擎内过场。
- 贯穿全篇的三条线：
  1. **主线**：追查余烬之心碎裂的后果 → 揭开修会的真相 → 阻止首席灯主阿尔德温。
  2. **心中之火**：主角体内的厄鲁斯从「低语」变成「对话者」，最后成为结局选择的一方。
  3. **伊莲之线**：伊莲寻找哥哥卢西恩的下落，最终要在「救回哥哥的残影」和「放他安息」之间做选择。

## 三、分章大纲

### 序章 · 余烬之心（烬原）

对应已上线的 V0.1，3D 版重做，情节不变。

- **地点**：烬原镇、圣焰修道院地窖、白骨墓穴、熔渊封印大厅。
- **主线**：伊莲请主角查明地窖里的钟声 → 救出铁匠学徒托比 → 在封印大厅击败摩登院长。
- **首领**：
  - 章中：**腐肉监工 莫格**。3D 版造型调整：去掉 V0.1 的屠刀和围裙，改成拖着铁链、背负囚笼的**监工**形象，驱使灰尸劳作，和经典的「屠夫」原型拉开距离。
  - 章末：**堕落院长 摩登**（两阶段）。
- **结尾**：余烬之心碎裂，火种钻进主角掌心。第一次听见厄鲁斯的声音：「容器……终于找到你了。」
- **钩子**：伊莲看见主角眼里的火，沉默良久，说出一个名字——「卢西恩」，然后改口说没什么。

### 第 1 章 · 溺者之歌（哀泣沼泽）

- **地点**：沼泽渡口营地、被淹没的村庄群、巫母会的朽木高塔、溺骸之池。
- **起因**：修会派来的使者要求主角去光冕城「接受净化」；同一天，沼泽方向的难民说整村整村的人被「唱」进了水里。伊莲劝主角先去沼泽，修会的事以后再说。
- **本章敌人**：灰誓教团的**灰先知 萨卢**。他把活人沉进沼泽，让他们变成灰尸，想用尸体里的火种唤醒一位焚天者。
- **关键事件**：
  1. 在营地遇到巫母**茉恩**，她一眼看出主角体内的火种：「你身上有八个人。」（厄鲁斯 + 七守誓者的残余）
  2. 主角第一次「忘记」：在村庄里帮一个女孩找回母亲后，下一段对话里主角已经想不起女孩的名字（系统上：一段日志被划掉）。
  3. 厄鲁斯在关键时刻主动出手救了主角，并对萨卢说：「你们唤醒的不是我的同类，是在给北边送柴。」——第一次暗示他另有目的。
- **首领**：
  - 章中：**溺骸巨像**（由上百具尸体缠成的巨人，从水里站起来）。
  - 章末：**灰先知 萨卢**。战斗中他会唱歌，把玩家的召唤物和友方 NPC 拉进水里。
- **结尾**：萨卢临死前狂笑：「修会也在收集火种，只是他们收的是活人。」
- **钩子**：茉恩给主角一块「寂」之石，能封存一段记忆不被火种吃掉。主角要选择封存哪一段（纯叙事选择，影响后面几句台词）。

### 第 2 章 · 铜与沙（沉沙海）

- **地点**：沙漠绿洲城「铜铃集」、掘火者矿场、半埋的帝国火种引擎城、玻璃化的熔岩地。
- **起因**：追查萨卢的遗言，发现修会与掘火者行会之间有秘密的「火种合同」。托比坚持同行，想见识帝国的烬械。
- **本章敌人**：掘火者行会会长**铜面 巴拉克**。他的矿场用被抓来的承烬者当「活燃料」驱动引擎；他自己体内的火种快熄了，靠吞别人的火种续命。
- **关键事件**：
  1. 托比修好一台帝国时代的炉铳，从此成为营地里的烬械工匠。
  2. 矿场深处关着十几个承烬者，其中一个老人记得三十年前：「修会的人来抓过承烬者，说要凑够七个。」——真相 3 的第一条线索。
  3. 主角可以选择先救矿工还是先追巴拉克（影响本章结尾谁活下来，不影响主线）。
- **首领**：
  - 章中：**沙蠕引擎**（帝国留下的巨型掘地机械，被巴拉克重新点燃）。
  - 章末：**铜面 巴拉克**，驾驶烬械战甲；第二阶段甲胄破碎，露出火种将熄、半透明的身体。
- **结尾**：巴拉克的账本记着：行会最大的买家一直是「光冕城 · 首席灯主办公室」。
- **钩子**：账本最后一页夹着一张帝国时代的地图，标出了萨兰废都的「火种档案馆」。

### 第 3 章 · 永燃之帝（赤叶峡谷 · 萨兰废都）

- **地点**：雾气弥漫的红叶峡谷、悬空栈道、藤蔓覆盖的帝国神庙群、巨像守卫的档案馆、地底的皇帝陵寝。（这一章的美术对标所有者提供的参考图的**氛围**：红叶、浓雾、废墟、巨像。）
- **起因**：去档案馆查修会与帝国的关系。
- **本章敌人**：帝国末代皇帝的残骸**永燃之帝 瓦尔提斯**。大熄时他把全城的火种灌进自己体内，活了三百年，早已疯了，只剩「燃烧」这一个念头。
- **关键事件**：
  1. 巨像守卫：峡谷里的石像是帝国的烬械哨兵，会在雾中苏醒。
  2. 🔒 档案馆的壁画与记录揭开**真相 2**：帝国晚期，修会使者劝皇帝「加速开采以对抗北方」，并在大熄当夜带走了帝国的火种储备。壁画上那位使者的脸，和光冕城里供奉的首席灯主**阿尔德温**一模一样——三百年前就是他。
  3. 厄鲁斯第一次主动讲述自己的过去：三十年前他破土而出，是因为感知到寒寂突然加速。**真相 1 在这一章完整揭开。**
- **首领**：
  - 章中：**石冠巨像**（峡谷中最大的巨像，场地战：栈道会断裂）。
  - 章末：**永燃之帝 瓦尔提斯**。他燃烧得越久越强，玩家要熄灭陵寝四角的火盆削弱他。
- **结尾**：瓦尔提斯死前恢复片刻清醒：「北墙……撑不住了。」
- **钩子**：同一时间，信使带来消息：铁冠山脉的霜墙出现了第一道裂缝。

### 第 4 章 · 霜墙（铁冠山脉）

- **地点**：石窟城「火塘堡」、雪崩古道、霜墙要塞、墙外的冰原前哨。
- **起因**：石誓部族向所有人求援，只有主角来了。
- **本章敌人**：寒寂本身与它的造物**空壳**。第一次大规模出现冷色敌人，战斗节奏变慢、压迫感更强。
- **关键事件**：
  1. 族母**赫尔嘉**不信神也不信魔：「火就是火，灶台里的火也能暖人。」——这是结局「放手」的思想种子。
  2. 🔒 最后一位持灯者**白灯 伊奥**在霜墙现身。她和主角体内的厄鲁斯隔着主角的身体对话，揭开**真相 4**：持灯者与焚天者都在应对寒寂，第一长夜之后的一切，都是两种末日方案之争。
  3. 霜墙崩塌。**赫尔嘉战死**，用身体和部族的火塘堵住缺口，给主角争取撤退时间。
- **首领**：
  - 章中：**雪崩之母**（被寒寂侵染的巨型雪兽）。
  - 章末：**霜墙吞噬者**（从裂缝里挤进来的巨大空壳，没有脸、没有声音；战斗中声音会逐渐消失，玩家只能靠画面判断攻击）。
- **结尾**：伊奥告诉主角，七盏圣灯是维持南方温暖的关键，要去光冕城确认它们是否安好。
- **钩子**：伊莲在烬原收到修会的调令，被召往光冕城。她给主角留了一封信：「如果在那里见到我，别让我做傻事。」

### 第 5 章 · 七灯之城（光冕城）

- **地点**：白色圣城的上城区、七灯神殿、修会审判庭、城下的巨型地下监狱「灯窖」。
- **起因**：主角潜入光冕城查看圣灯，同时寻找伊莲。修会已把主角列为头号异端。
- **本章敌人**：审判长**铁灯 盖里克**与首席灯主**阿尔德温**。
- **关键事件**：
  1. 🔒 **七灯已熄六盏**：神殿里只有一盏圣灯真的在烧，另外六盏靠从灯窖里抽取承烬者的火种伪装。**真相 5**。
  2. 🔒 **主角的身世**：灯窖是修会培育承烬者的「苗圃」。主角就是在这里长大的备用容器，一年前在一次火种试验中逃出，记忆被烧掉——所以才能承受余烬之心。
  3. 🔒 **真相 3**：七守誓者是修会挑中的七个承烬者，不是自愿的。卢西恩被带走时二十岁。
  4. 🔒 **伊莲之线高潮**：伊莲发现卢西恩的残影就在主角体内。阿尔德温向她许诺，只要把主角交出来，就能用灯窖的技术让卢西恩「回来」。伊莲的选择由玩家在对话中影响（信任度来自前几章的累积）：
     - 高信任：伊莲拒绝阿尔德温，帮主角逃出灯窖；
     - 低信任：伊莲一度背叛，在最后关头醒悟，为主角挡下一击（重伤，存活）。
- **首领**：
  - 章中：**铁灯 盖里克**（审判长，用修会的「节制之火」压制玩家的燃系技能）。
  - 章末：**阿尔德温（第一形态）**。战斗打到一半，他吞下最后一盏真正的圣灯，打破神殿穹顶逃往炉心。
- **结尾**：光冕城的温度开始下降，南方第一次下雪。
- **钩子**：伊奥说，想追到炉心只能走最短的路：穿过霜渊。

### 第 6 章 · 长夜（霜渊 → 炉心）

- **地点**：霜墙之外冻住的海、被抹去颜色的古城、无声的冰原；然后下到大陆中心的**炉心**，熔岩河与始焰残骸化成的水晶骨林。
- **本章敌人**：寒寂的使者**无名者**；伪始焰**阿尔德温**。
- **关键事件**：
  1. 霜渊里没有声音、没有颜色。火种在这里会一点点熄灭，主角每前进一段就要做选择：燃烧记忆换取温度，还是用「寂」之石保住自己（叙事选择，影响终局台词）。
  2. 🔒 **无名者**是第一位被寒寂掏空的承烬者：面容和主角一模一样，是「如果主角放弃自我会变成什么」的镜像。
  3. 🔒 在炉心，阿尔德温已把七盏圣灯的火种和自己熔在一起，自称新的始焰。他的最后一段话是真诚的：「总得有人来烧。我烧了三百年，不是为了自己。」
  4. 🔒 **真相 6**：阿尔德温倒下后，始焰残存的最后一点意识向主角开口。主角体内的厄鲁斯、卢西恩的残影，以及伊奥（通过圣灯）都在场。
- **首领**：
  - 章中：**无名者**（使用与玩家相同职业的技能组，镜像战）。
  - 最终：**伪始焰 阿尔德温**，三阶段：圣者（光与节制）→ 七灯（七种火焰轮替）→ 熔毁（场地逐渐坍塌、寒寂从边缘涌入）。

## 四、终局选择与三个结局

击败阿尔德温后，主角站在始焰的残骸前做出选择。三个选项始终都能选，前面章节的累积只改变台词和结局画面里的细节，不锁结局。

| 结局 | 选择 | 谁支持 | 发生什么 | 尾声画面 |
|---|---|---|---|---|
| **重燃** | 把体内所有火种连同自己一起投进炉心 | 厄鲁斯 | 始焰重生，旧世界在火中消亡，新世界从灰烬里长出来 | 数百年后，一片新绿的烬原上，孩子们围着篝火讲一个没人记得名字的英雄 |
| **延续** | 成为新的持灯者，像七守誓者一样把自己封进灯里，但这一次出于自愿 | 伊奥 | 南方重新变暖，世界再多活几百年；寒寂只是被推迟 | 伊莲在烬原修道院点亮一盏新灯，灯芯里的火偶尔会像人一样跳动 |
| **放手** | 让残存的火种自然熄灭，用「寂」之石把所有人的记忆保存下来 | 赫尔嘉的遗言、茉恩 | 长夜降临，但人们学会在没有火种的世界里靠灶火和彼此活下去 | 火塘堡的孩子们在灶火边学写字，墙上刻着所有被记住的名字 |

- **卢西恩的去留**在终局前由伊莲决定（第 5 章信任度影响她的选择）：让残影安息，或者让他随主角的选择一起走。
- 结局之后开放**无尽深渊**（沿用 V0.1 的设计）：「炉心之下还有更深的裂隙」，作为长线刷装备玩法。三个结局都能进入，结局只影响深渊入口处的一句台词和主城外观。

## 六、原创性自查（结构层面）

| 可能被联想的暗黑元素 | 本作的处理 |
|---|---|
| 暗黑 1「英雄把魔王的灵魂石插进自己额头」 | 本作序章结尾有类似的「吞下火种」时刻，但之后走向完全不同：厄鲁斯是可对话的同盟与结局的一方，不是要夺舍的魔王；主角身世另有来历 |
| 「屠夫」首领（胖大、屠刀、围裙、「新鲜的肉」） | 3D 版莫格改为铁链监工造型；V0.1 的造型与台词建议后续也调整（见路线图待办） |
| 天堂与地狱的永恒冲突 | 三方结构，神魔都在应对第三方「寒寂」；真正的反派是以拯救为名的凡人 |
| 七大魔王 / 三大魔王 | 本作没有「魔王家族」，焚天者只出现厄鲁斯一位 |
| 大天使堕落（马萨伊尔 / 伊纳瑞斯） | 阿尔德温是凡人，不是天使；他的动机是「管理末日」 |
| 结局单一、为续作留魔王复活的钩子 | 三个可选结局，每个都给出世界的最终形态 |

## 七、交给后续步骤的事项

- 0.3 游戏设计文档：「遗忘」要不要做成系统（例如日志被划掉、某些对话选项消失），还是只做叙事演出；伊莲信任度的累积方式；三个职业的技能框架。
- 0.4 美术方向：每章主城 / 野外 / 地下城 / 首领的视觉关键词，第 3 章萨兰废都作为垂直切片候选。
- 阶段 5 内容生产：每章拆成「主城 → 野外 → 地下城 → 首领 → 过场」五个步骤。
- V0.1 待办：莫格的屠刀、围裙与开场台词偏向经典「屠夫」原型，建议改为铁链监工（小改动，可单独一个步骤）。
