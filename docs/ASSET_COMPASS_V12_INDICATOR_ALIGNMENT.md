# 全球资产罗盘 V12｜指标缺口回补：核心 CPI 与纽约联储衰退概率

## 设计回归

原始 V1 的“美国 CPI、核心 CPI”应当拆成两个不同的 BLS 序列；纽约联储未来12个月经济衰退概率是额外的辅助风险指标，并不是核心18项全部完成的替代。配置现在有20个独立注册条目（原18条加核心CPI与NYFed衰退概率），其中仍有多项待接入。

### 已完成：核心 CPI 正式数据接入

- **权威来源**：BLS Public API v1 `https://api.bls.gov/publicAPI/v1/timeseries/data/`。
- **独立序列**：`CUSR0000SA0L1E`，美国城市平均、城市居民CPI-U、剔除食品及能源、季节性调整。
- **本期值**：指数水平，`core_cpi.value` 与 `core_cpi.period`。
- **同比**：如上年同月官方指数可用，计算 `(当前值/去年同月值-1)*100`。如基期缺失，`yoy_percent` 不提供，不插值。
- **更新机制**：复用现有工作日 `macro-treasury.yml` 官方BLS采集流程；采集成功后随 `data/asset-scores.json` 一并发布。页面验证数据最近三个自然月才显示。
- **归档**：独立系列 `bls.core_cpi` 写入首次观测档案；注意首次采集时间**不等于**官方最初发布日。
- **禁用状态**：即使核心 CPI 报价成功，也不能凭此声称完整六因子评分可以上线。

### 已定义、尚未抓取：纽约联储衰退概率

- **权威来源**：<https://www.newyorkfed.org/research/capital_markets/ycfaq.html>
- **模型**：纽约联储期限结构模型，使用**美国10年国债收益率减3个月国库券利率**。
- **含义**：在当前模型时点预测“12个月后的月份”发生衰退的概率，不等价于“未来12个月内任何时候均可能衰退”的累计概率。
- **更新频率**：月度；官方一般在每月前两周更新。
- **发布限制**：官方明确不是纽约联储/联储系统的正式预测。现阶段没有经过校验的结构化月度数据链路，因此不会硬填实时值，也不会用10Y-2Y利差自算成官方概率。
- **进一步工作**：确定可自动获取且获授权的结构化原始月度文件，记录预测基准月、预测目标月、官方下载来源以及当时官方发布时间，并做在线可信度测试。

### 数据质量与行业注意事项

- 当前 BLS 查询会取得现行修订版本；**不能直接用于回填过去的历史首发版本**。
- CPI-U（所有项目）与核心 CPI 均为季调指数；两个同比值所用的当期与上年同月观测必须来源一致，不能拼接不同版本。
- 10Y名义利率、10Y实际利率与隐含通胀补偿存在数学关联；它们不得被不加区分地当成三个独立因子反复加权。
- 本阶段无新的 Cloudflare D1/R2 操作，无正式资产评分发布或基金配置建议。
