# Ooglex 全球资产罗盘｜V47 国债收益率跨指标同期变化研究

## 目标
使用 V42–V46 已发布的**同日配对**美国国债及10年TIPS历史收益率数据，量化两个所选收益率序列的*变化相关性*与同步程度，不对利率水平做可能产生伪相关的简单比较，不把结果转为投资评分。

## 实际功能
1. 现有双曲线和时间范围（近3个月、近1年、全部历史）同步驱动 V47 相关性面板。选择两条不同曲线时，取同一资料源的同一对相邻观测日，分别计算收益率变化（基点bp）。
2. 计算同期变化的 **Pearson 相关系数**（−1到+1），并显示样本数、首末变化日期。同向/反向/至少一方不变的次数单独显示，同向比例只对双方均非零的变化计算；没有有效非零变化则不计算同向比例。
3. 以最新20组、60组收益率变化作为滚动相关窗口，报告末端相关系数及历史有效滚动窗口数。仅用于说明历史共变程度，不构造滞后信号或因果解释。
4. 少于10组变化、重复或错误日期、无效数值、双曲线为同一指标，以及**任意一方变化方差为零**时不发布相关系数；不得制造0或1作为假值。
5. 重要：同一官方观测口径满足 `10年名义＝10年TIPS实际＋10年通胀补偿`，`10Y−2Y期限利差＝10年名义－2年名义`。四条可视化曲线并非四个独立预测信号；高相关/反相关不证明对未来资产收益有预测能力。
6. 继续保持 `original_release_vintages_available=false`、`not_valid_for_point_in_time_backtest=true`，未认证的六资产0–100评分、正式历史回测收益和自动预警全部关闭。

- 实际同日期 bp 变化和分布；
