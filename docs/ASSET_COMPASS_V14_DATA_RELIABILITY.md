# 全球资产罗盘 V14｜FRED 下载故障修复与数据源独立验收

## 实际故障
V13 GitHub Actions 对 `https://fred.stlouisfed.org/graph/fredgraph.csv?id=PCEPILFE` 连续超时；原采集流程一次尝试下载所有历史数据，两源绑定意味着PCE失败会直接阻止H.4.1入库。

## 本期改动
- 只请求固定有限历史：核心 PCE 近约3年（用于上年同月同比），WALCL 近约1年，分别附 `cosd`、`coed` 查询参数。
- 两个序列独立下载、校验、写入；失败只标记 `PENDING_EXTERNAL_SOURCE_VALIDATION`，**不会自动回填推断数值**。
- 每个序列各自记录源地址、当前观测日期、首次采集时间，研究页面继续在无数据时显示「暂无数据」。
- GitHub CI 分别输出各源 `VERIFIED SOURCE` 或 `SOURCE NOT VERIFIED`，禁止把工作流通过等同于两源都已真实取数成功。
- 纽约联储12个月后衰退概率官方月度数据仍需独立机器可读文件解析与时点审计，未接入前不显示数值。

## 继续受限
- 即使成功取值，也只是当期镜像的最新修订版，不提供当年的官方历史发布版本；尚不满足投研回测入场要求。
- 数据使用授权、模型校准、完整六因子仍需另行审核，六资产综合评分继续锁定。

## 实际在线验收结果（GitHub Actions PR #411）

- 新版有限窗口 FRED CSV 实际成功返回 `PCEPILFE`，最新 BEA 核心PCE 指数观测期为 **2026-09**。
- 新版有限窗口 FRED CSV 实际成功返回 `WALCL`，最新美联储H.4.1总资产观测日为 **2026-11-18**。
- 两来源分别通过解析、校验和独立归档检查，研究测试归档12项。指标注册表据此标记 `implemented`。
- **注意**：这只确认 GitHub Actions 可以获取当期官方统计的 FRED 镜像，仍不是完整历史发布版本，也不证明站点生产定时采集已经持续执行。
