## 本次实际完成与未完成

已实现六资产**总回报口径定义与可复核算术函数**，不是六资产总回报历史数据的取得。六资产研究来源仍根据 V59 真实采集报告统计，评分不开放。

此前 `scripts/prepare_asset_compass_returns.py` 使用 Yahoo/CoinGecko 观察价格计算相邻收盘涨跌，不含分红、利息、期货展期、融资及交易费，不能作为投资总回报。V60 的 `scripts/build_asset_compass_returns_v60.py` 不修改这些原有研究脚本，而是新增更严谨的会计口径和逐期现金流对账，缺项直接拒绝。

## 算法约束

- ETF：逐期单份资产起始净值与期末拆并股调整后价值，加上期间现金分配，扣掉手续费和滑点，再除以期初价值。真实运作必须明确现金分配再投资时点和份额路径；现阶段只支持**持有现金分配到期末**的单期算术。
- BTC：持仓单位不变且无外部资金流时，期末单位价值扣除完整费用，除以期初单位价值；不同单位或资金流拒绝计算。
- 美元：采用 **USD/一单位外币** 报价方向，明确美元持有利息和外币借款利息；避免只看指数涨跌就给出总回报。
- 原油期货：以期初抵押现金权益为分母；实际持仓P&L、展期已实现P&L、未实现盈亏、抵押现金利息及完整费用必须与期末现金权益对账，否则拒绝。
- 这些核对公式验证的是**输入是否有明确会计意义、算术能否对账**；无论测试是否通过，都不认证历史数据授权、PIT、全市场可投资回报、OOS或0–100分。
- 所有测试数字仅作为完全隔离的**模拟会计样例**；不写入数据目录，不参与网站展示或交易评级。

## 下一阶段实际数据任务

1. 从已公开许可或具备授权的源获得具体ETF的历史NAV+所有现金分配，核对拆并股和交易成本；这是跨资产可比收益的第一批真实样本。
2. 期货根据到期月份和实际成交/结算保存合约表、展期日期、PnL与抵押现金，而非连续合成价格。
3. 外汇先固定对手货币及仓位杠杆/融资条款，避免“美元指数涨1%=美元投资赚1%”。
4. 每个历史宏观信号记录当时真实发布日期、修订版本、信息可用时间，再做严格带purge的walk-forward OOS和真实可投资收益检验。
5. 在上述条件全部满足之前，六资产各自评分均保持 `null`。
