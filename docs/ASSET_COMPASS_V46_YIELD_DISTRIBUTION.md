# Ooglex 全球资产罗盘｜V46 收益率历史经验分布与异常波动观察

## 交付范围
继续使用现有 `data/asset-compass-treasury-history.json`，不重复抓取，不建立新新闻稿/备份系统。图表指标仍为10年期名义收益率、10年期TIPS实际收益率、10年通胀补偿与10Y−2Y期限利差。仅用于宏观研究，不作资产评分。

V46在 V42–V45 双曲线和区间高低值统计下方增加：

- **当前收益率经验分位**：`100 × (低于当前收益率的观测数 + 0.5×等于当前收益率的观测数) / 样本量`。采用并列值中秩，属于**包含当前点的样本内经验秩**；不是资产分数、价格预测或实时预警。
- **P10、中位数、P90**：由实际收益率按数值排序，用线性插值的样本分位数展示，明确样本区间与观测日数量。
- **相邻实际观测日变化**：以相邻有记录的日期 `(本次收益率−上一观测收益率)×100` 计算 bp；不把周末或假日补作交易日，精确至0.01bp再分桶。
- **正负变化幅度分布**：七个互斥分桶 `≤−20`、`(−20,−10]`、`(−10,−5]`、`(−5,+5)`、`[+5,+10)`、`[+10,+20)`、`≥+20` bp。总样本数为收益率观测日数减1。
- **样本内异常观察**：将相邻实际观测日的**绝对bp变化**排序，按P95经验分位阈值提示最近一次变动是否达到该阈值；展示达到阈值的历史样本次数及绝对变化最大的五次历史记录（上一日、本日及带符号bp）。
- 当只选主曲线时展示一套；选两条曲线则分别展示两套，绝不把不同来源或不同观测期强行补配。

## 数据与限制
原始日度历史JSON具有 V42 官方来源验证：美国财政部历史CSV（如未来断连则允许单一、明确标注的美联储H.15经FRED镜像），曾确认1,472个实际匹配观测日，最新 2026-11-20；随着真实历史发布，样本数可增长。所有分位数使用实际展示图表时间范围（3个月、1年或全部历史），因此**变更范围会改变分位统计口径和P95阈值**。

严格区分历史样本内分位数与 V45“当前在历史最高最低值之间的位置”；不能误认为概率、投资资产评分、真实未来收益或具有PIT审计资格的历史预测。0–100资产评分、历史PIT回测以及投资提醒继续锁定。
