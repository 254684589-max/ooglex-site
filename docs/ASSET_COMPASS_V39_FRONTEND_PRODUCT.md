# Ooglex 全球资产罗盘 V39｜回到真实前端产品

## 为什么做本阶段
V28–V31 已接入14项真实宏观指标，V34–V38 则主要建设历史新闻稿取证与异地备份，偏离了“让用户在网站上浏览宏观数据、理解六资产研究依据”的核心交付。

**V39 不新增新闻稿、历史审计、云存储或预测模型。** 它复用已经上线的四个页面，把 `/macro/overview.html` 升级成真正有用的总览落地页，不重复制造另一个页面系统。

## 本阶段实际功能
1. 网站首页入口由 `macro/` 改为 `macro/overview.html`，直达产品总览；现有 `/macro/index.html` 仍保留完整指标中心。
2. 直接通过同源 `../data/asset-scores.json` 读取14项必需宏观数据；不使用演示行情或前端伪造数值。涉及美国国债3项、EFFR、BLS四项、BEA核心PCE、联储H.4.1、银行准备金/TGA/隔夜逆回购，以及纽约联储研究性衰退模型。
3. 展示利率核心观测、每项指标的名称/真实值/观测期/来源/可用状态。支持类别筛选和关键词搜索，移动端可横向滚动表格。
4. 对来源分别执行宽松但明确的**前端展示新鲜度门槛**：日频最多11自然日、周频21自然日、月频4个日历月。缺失或过期不以零代替。快照72小时以上未更新明确显示延迟警告；快照延迟警告不代替逐系列门槛。
5. 六资产仍使用现有模型定义：黄金、美股、美国长期国债、美元、比特币、**原油**。每张卡显示分析关注点及进入因子权重/回测准备度的链接，但没有市场方向、胜率、0–100虚构评分。
6. 首次观测历史只展示归档记录数量，不当作独立交易日或已认证的PIT版本。所有结果仅为宏观研究观测，非实时行情或投资建议。

## 注意
- 该阶段**不改变**后端评分器、采集流水线、原始数据、模型初始权重或历史归档。
- 数据中的CPI同比若缺少官方对应基期，页面显示 CPI **指数水平**，不会把价格指数误写成CPI同比涨幅。
- BEA核心PCE显示官方最新修订镜像的同比，需通过历史发布时间审计才能用于PIT回测；NYFed收益率曲线衰退概率是研究模型而不是官方经济预测。
- 实际利率、名义利率、通胀补偿有代数联系，不能当作互相独立的三票；TGA等流动性单位和频率不同，不能直接加总为交易信号。
- 模型未完成历史校准与样本外验证，**六资产评分和预警仍全部关闭**。
