线上：https://ooglex.com/apps/supply-chain/

- **495 家**标普成分股，全部按 SEC 官方 SIC 行业码判定环节，无一家未归类

## 二、数据源判决（已实测，不要重复探）

| 源 | 结论 | 依据 |
|---|---|---|
| SEC Form SD 冲突矿产 | ✅ **已接入** | 唯一在产的关系源 |
| SEC 正向抽取（10-K 客户集中度） | ❌ 否决 | ASC 280 要求披露幅度、不要求披露身份 |
| SEC 全文检索反查 | ❌ 否决 | 「提到」≠「有供应关系」，误报率不可接受 |
| 公司自发布供应商名单 | ⚠️ 八家里只有思科可用，**但内容已能读出** | 见下 |
| USAspending 联邦采购 | ⚠️ 暂不接 | 想补的板块恰恰没有分包记录；按名字搜有假阳性（搜 Leidos 出 KALEIDOSCOPE）；需 UEI 锚点 |
| BDI / Drewry / Freightos / Xeneta | ❌ 许可禁止 | 商业授权，与已放弃的 SPX／DXY／LBMA 同类 |

## 三、待办（按价值排序）

### P1 · 149 家「有申报未列名单」还能挖

这一档是目前唯一确定能拿到**更多真实数据**的地方。迪尔那 402 家就是从这里
抠出来的（卡在 `Gold (Au)` 的元素符号上）。至少还有三种情况：

- [x] **申报的是资源开采付款不是冲突矿产** — 13q-1 与 13p-1 是两套互不相干的
      披露，康菲、纽蒙特属于后者，那套披露里没有冶炼厂这个概念。已单列一档，
      不再算进「未列名单」。
- [x] **PDF 文本抽取器**（P1 与 P2 的共同地基）— `scripts/supply-chain/pdf_text.py`，
      纯标准库。过滤器覆盖 Flate / ASCII85 / ASCIIHex / LZW / RunLength 与
      PNG 预测器，展开对象流。判据分四种，解不开时明说是解析器能力不足，
      **不说成「文件没有文字」**。
- [ ] **把 PDF 接进抽取器** — 抽取器的 `list_documents` 仍只收 `.htm/.html`，
      麦当劳 `formsd2026.pdf`（493KB）还是看不到。地基已就位，接线未做。
- [ ] **整份报告没有 HTML 表格** — 洛马、埃森哲、丹纳赫的 CMR 都是 33–34KB
      但 `<table>0 <tr>0`。要点开原文看名单在不在，**不要猜**。

验收：每修一处，重跑全量后 diff「有名单」家数，并抽检新入库公司的名字与国别。

### P2 · 思科名单抽取器（地基已通，2026-09-05 实测）

PDF 抽取器上线后复跑探针，思科两份文档的内容**已经读得出来**：

    cisco-supplier-list.pdf   256KB  打分 25 → 1 页 1,969 字
        「Cisco Supplier List — Cisco products are made by a complex
          global network of manufacturing partners…」
    smelter-refiner-list.pdf  475KB  打分 16 → 9 页 19,273 字
        「Cisco Responsible Minerals 3TG Smelter…」

**这是 Form SD 之外第一份读得出内容的一手名单。** 下一步是把这 9 页文本
解成条目并挂上出处。注意两件事：

- 语义与 Form SD 的冶炼厂**不同**：思科那份供应商名单是一级供应商，
  不能沿用 `smelter-in-supply-chain` 那条关系，要新定义并写清含义。
- 现有解析器是**按 HTML 表格**写的，PDF 出来的是文本行，需要另一套行解析，
  不能直接复用。

对照组行为正确：摩根大通无候选；英特尔三份 PDF 仍解不开，如实报
「本探针能力不足，不能据此说文件没有文字」，不假装是扫描件。

## 四、下次怎么接着做

对话里说 **「继续开发产业链」** 或输入 **`/supply-chain`**，
会自动加载 `.claude/skills/supply-chain/SKILL.md`（口径、坑、校验、收尾）
与本文件（状态与待办），然后从 P1 往下推。

想指定方向就在后面加一句，例如：

- `继续开发产业链，先做 P1 里的 PDF 抽取`
- `继续开发产业链，这次只做校验和文档，不动数据`
- `继续开发产业链，做完直接上线`（= 明确授权合并到 main）

**不加「直接上线」时，默认做到提交分支为止，等你确认再合并。**
