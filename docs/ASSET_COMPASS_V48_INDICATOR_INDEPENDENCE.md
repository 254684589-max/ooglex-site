# Ooglex 全球资产罗盘｜V48 指标独立性与重复信息审计

## 核心目的
V39–V47 已建立14条宏观指标源系列、2种同日国债收益率代数派生指标和历史相关性分析。**14条官方数据源系列不等于14个独立预测信号。** V48 在用户可见的全球资产总览添加逐项来源依赖台账，在历史资产评分被认证之前先识别确定的数学重复与经济口径重叠。

## 网站实际展示
1. 在 `macro/overview.html` 的14项宏观数据表下、六类资产卡片上方新增“宏观指标独立性与重复信息审计”模块，使用`macro/compass-pages.js`现有指标注册表动态核对**14项完全覆盖**。
2. 逐项显示指标名称、研究主题、实际数据频率、会计/统计依赖与当前数据可用状态。明确不同机构的统计系列并不自动保证预测独立性，同一机构的不同统计口径也不必然是数值完全重复。
3. 显示两种**精确定义的派生恒等式**：
   - `10年名义收益率 = 10年TIPS实际收益率 + 10年通胀补偿`；
   - `10Y−2Y期限利差 = 10年名义收益率 − 2年名义收益率`。
   以上派生数值可作为分析图表，但不得增加一个独立数据源或重复计票。用真实已提交的1472个官方财政部观测日核对以上公式容差。
4. 明确展示BLS总体CPI与核心CPI统计口径共享、BEA核心PCE价格资料部分重叠、就业家庭调查和企业调查区别、联储H.4.1资产与准备金/TGA/逆回购的会计体系联系、纽约联储衰退概率作为期限利差的模型输出，而不是新独立期限信号。
5. 审计报告不推导所谓“目前有X个经认证独立因子”。主题组数仅是信息组织分类，真实**预测独立性认证数量仍为零**，6资产0–100评分、PIT回测和自动预警继续关闭。

## 与既有研究架构的关系
`scripts/asset_compass_independence_v22.py` 已提供有真实历史发布日期凭据的私有研究独立性诊断要求，V48不绕过、不替代该要求。V47同期变化相关性仅证明样本内共动/反向运动，**不能用高/低相关自动宣布指标完全冗余/独立，也不能用于未来收益预测**。
