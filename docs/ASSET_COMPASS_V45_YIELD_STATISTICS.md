# Ooglex 全球资产罗盘 V45｜3个月、6个月、1年收益率区间统计

## 核心目标
延续 V42–V44 已接入的**真实美国财政部同日历史收益率观测**。在现有名义10年、实际10年、通胀补偿、10Y−2Y双曲线下方，直接呈现可核查的描述性统计，不增加新闻稿、备份、模型预测或第三方数据库。

## 新增统计及口径
- 时间窗口 **3个月（92自然日）/6个月（183自然日）/1年（366自然日）**。每个窗口都以实际历史文件的**最新观测日**为终点，不以当前系统日或假设交易日强行补齐。
- 每个窗口分别展示实际观测日数量、最低值（及日期）、最高值（及日期）、算术均值、最新收益率、首末收益率变化（bp），以及最新值处于该窗口最低和最高收益率之间的位置。
- 首末变化按 `(终点收益率 − 起点收益率) × 100` 计算 bp；正负号保留。两个系列分开展示，不把其相加当成信号。
- **区间位置**为 `(最新收益率 − 最低收益率)/(最高收益率 − 最低收益率)`，这是一个观察值相对历史高低点的比例；**不是分布百分位、投资信号、模型评分或涨跌概率**。如果窗口高低收益率相同，直接显示“区间无变化”，不虚构中位数。
- 窗口内不足2个经日期检查的实际观测日，显示“统计不可用”。不得用插值、周末填值或模拟数据制造统计。
- 如果双曲线已选择，就分别显示两套统计；单曲线只显示一套。数据JSON通过现有 V42 官方来源/数学审核。
