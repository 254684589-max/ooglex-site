# Ooglex 全球资产罗盘｜V41 六资产宏观依据交互

## 本阶段目标
在已经运行的 Ooglex `/macro/overview.html` 中，不再只有六资产空评分卡。用户点选黄金、美股、美国长期国债、美元、比特币、原油时，页面显示与该资产有关的**真实当前宏观观测、观测期、来源及研究含义**。本次不新增新闻稿取证、云端备份、宏观采集、历史回测或交易建议。

## 实际交互
- 六个资产卡各提供“查看宏观依据”按钮。页面默认选择黄金，点击按钮动态更新下方解读区域；按钮同步更新 `aria-pressed`，区域具有 `aria-live`，适应移动端单列。
- 每个资产有4条明确的宏观研究依据，总共24条资产—指标对应关系；对应指标来自 V39–V40 同一个 `overviewObservations` 的真实值和有效期规则，不允许另造数值。
- 黄金：实际收益率、10年期通胀补偿、核心PCE、EFFR。
- 美股：10年名义收益率、非农月增量、失业率、核心PCE。
- 长期美债：名义10年、实际10年、10Y通胀补偿、10Y−2Y利差。
- 美元：EFFR、2年及10年美债收益率、核心PCE。**没有海外利率和实际美元指数数据就不做方向预测。**
- 比特币：EFFR、银行准备金、实际10年收益率、纽约联储研究模型。**缺少资产专属资金流和市场风险因子。**
- 原油：非农就业、失业率、核心PCE、10年国债收益率。**缺少OPEC产量、原油库存及期货期限结构。**
- 10年盈亏平衡通胀补偿由**同一观测日**名义10年与实际10年收益率相减得到；10Y−2Y利差由同日10年和2年名义收益率相减得到，两者明确标记为“派生、非独立来源”，不会增加14项原始必需源的计数。
- 未取得有效观测日期或原始数值时显示“数据缺失或过期”，不沿用其他指标的过期值，不以零填充。

## 验收与限制
- 不改变原有模型权重、数据文件、评分资格、回测工具和站点其他三个宏观页面。
- `node tests/smoke_asset_compass_insights_v41.cjs` 用真实浏览器JS逻辑和模拟DOM验证六资产按钮交互、每资产4项观测、过期回退、派生值正确性及全部评分仍显示“— / 100”。
- 运行 V18–V41 的完整研究门禁和原有 V40 前端测试；合并后核对主分支及 GitHub Pages 工作流执行结论。
- 此为**资产宏观指标解释**，不是因子贡献、自动方向、可回测策略、0–100量化评分、收益率或上涨概率。14/14 来源代表已经接入的数据源，不等于14条独立预测信号。
