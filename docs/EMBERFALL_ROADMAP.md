# 余烬陷落 EMBERFALL · 大作工程路线图与台账

> 这是台账：每推进一步，更新「当前状态」和对应阶段的状态列。接手前先读本文件，再读 `.claude/skills/emberfall/SKILL.md`。

## 目标（所有者，2026-09-25）

画质与剧情完整度向《暗黑破坏神：不朽》看齐：斜俯视 3D、写实暗黑奇幻、多章节完整主线；
**不抄袭**，世界观、人物、剧情、美术、音乐全部原创。

## 先说清楚的现实

| 维度 | 《暗黑破坏神：不朽》 | 本项目能做到的 |
|---|---|---|
| 团队 | 暴雪 + 网易，数百人、多年 | 所有者 + Claude；代码、玩法、剧情、着色器、程序化内容由 Claude 写 |
| 美术资产 | 专职原画、建模、动捕、特效团队 | **Claude 画不出 AAA 模型、贴图和动画**。需要：CC0 / 可商用素材包、AI 生成的概念图和贴图（所有者提供）、或外包美术 |
| 引擎 | 自研 / 商业引擎，原生客户端 | Godot 4.7（仓库已有网页导出管线：`games/working-life/tools/build_web.sh`） |
| 网页画质上限 | 不适用 | Godot 网页导出**只能用兼容渲染器**（WebGL 2）：没有 SDFGI、SSR、体积雾；靠烘焙光照、贴花、雾卡、调色和着色器补 |
| 原生画质 | 手机 / PC 原生 | 可另出桌面版（Forward+），画质上限高得多 |

结论：**网页版能做到「接近《暗黑破坏神 3》观感」的风格化写实**；真正向《不朽》靠拢需要桌面 / 手机原生版加上成体系的美术资产。
质量是否达标，在**阶段 3 垂直切片**结束时由所有者看实机截图决定继续还是调方向。

## 原创红线

- 不用：庇护所、崔斯特姆、赫拉迪姆、奈非天、世界之石、灵魂石、三大魔王 / 七大魔王、莉莉丝、伊纳瑞斯、泰瑞尔、迪亚波罗等任何专有名词，也不用谐音或近形名。
- 不复刻：具体关卡布局、人物外形、技能名与图标、UI 皮肤、配乐旋律、台词。
- 可以借鉴：玩法类型（斜俯视刷怪、随机词缀、首领战、赛季）、「封印松动 / 英雄被黑暗侵蚀」这类通用母题。
- 素材只用许可明确的：CC0、CC-BY（署名）、购买的商用许可；每个素材记入 `games/emberfall3d/assets/SOURCES.md`（来源、作者、许可、链接）。
- 不用暴雪游戏的截图、贴图、模型或音频做参考输入（包括喂给 AI 生成工具）。

### 阶段 P · 移植 V0.1（D9）

原则：
- **移植玩法与内容，不移植画法**：V0.1 的 Canvas 绘制代码不搬；地图、怪物、物品等在 3D 里用当前的程序化材质与占位模型表现，画质在阶段 2 / 3 再提升。
- 数据以 V0.1 `games/emberfall/play/game.js` 为源头，一次性转成 `godot/data/*.json`（记下对应的 V0.1 函数 / 常量名）；之后 3D 版的 JSON 就是唯一事实来源，V0.1 冻结不再同步。
- 已上线 V0.1 去掉的暗黑相似设计（屠夫造型、旋风斩 / 冰霜新星、红蓝球）不得带回；界面用火盆 / 油灯。
- 每一步都要有自动化测试，并更新 `/games/emberfall3d/` 介绍页「现在能体验什么」与截图；上线仍需所有者同意。
- 3D 版现有的「誓火」角色与 4 种怪物保留，按 D10 的决定处理与 V0.1 角色的关系。
