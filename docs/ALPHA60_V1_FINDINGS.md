# Ooglex Alpha 60 V1：研究结论

> 数据窗口：2017-08-22 → 2026-08-21（2514 个交易日，日线已校验）
> 股票池：371 只美国上市公司（取自当日市值榜）
> 尝试次数：5 次回测，3 个变体
> 结论日期：2026-08-24

## 一句话结论

**在「今日市值榜 371 只超大盘 + 免费日线」这个数据条件下，无法判断
Alpha 60 是否具有预测能力。整个研究里唯一达到统计显著的发现，
是证明这个回测本身不可信。**

这不是模型失败，是**数据不允许做这个判断**。两者的后续动作完全不同。

## 1. 模型侧：五次尝试，零次通过

| 变体 | 最佳 \|t\| | IC 均值 | 验收 |
|---|---|---|---|
| 风险块反向 | 1.32 | +0.0257 | ✗ |
| 去掉风险块 | 0.11 | −0.0031 | ✗ |
| 只用动量 | 0.00 | +0.0001 | ✗ |

基线 IC 均值 −0.0240，t = −1.09，95% 区间 [−0.067, +0.019]。

台账打折后的门槛已收紧至 **\|t\| > 2.58**（5 次尝试）。
最好的 1.32 离过线差一倍。

**「无法与 0 区分」不等于「模型是负的」。** 两者的区别是：前者该加数据，
后者该改模型。这里是前者。

## 2. 唯一显著的发现：幸存者偏差暴露 t = 2.98

策略历次选中标的的「今日市值排名分位」均值 **46.8**，随机基准 50，
优势 **+3.2 分位**，**t = 2.98**。

这个 t 值同时越过了三条线：

| 门槛 | 值 | 是否越过 |
|---|---|---|
| 普通显著 | 2.00 | ✅ |
| 多重检验校正（10 个独立因子群） | 2.81 | ✅ |
| 台账打折（5 次尝试） | 2.58 | ✅ |

**而模型本身最好的 \|t\| = 1.32，一条都没过。**

整个项目唯一测出来的显著效应，是「这个回测不可信」。

### 3.2 分位是偏差存在的证据，不是偏差的大小

这个指标只测了**幸存者内部**的偏向。真正更重的那部分测不到：

> 2017 年动量很强、后来崩掉 / 退市 / 被踢出榜单的公司，
> 从来没进过这 371 只——它们连被统计的机会都没有。

因此 3.2 分位**系统性低估**了偏差总量，真实量级无法从幸存者内部估计。

## 3. IC = 0 与组合 +380% 如何同时成立

| 持有期 | 累计超额 | 每期均值 | 年化超额 | 最大回撤 |
|---|---|---|---|---|
| 60 日（验收口径） | +379.95% | 4.70% | **21.3%** | 15.48% |
| 21 日（对照） | +240.26% | 1.24% | **15.9%** | 15.55% |

而同期 Rank IC 均值 0.0001，t = 0.00。

**解释是两条，且它们是同一件事：**

1. **信号只在极端头部。** 分组图里 D1 明显最高、D2–D10 小正数且乱序，
   单调秩相关 −0.018。Top-20 / 371 = 前 5.4%，正好吃那个头部。
   全体秩相关因此为 0，而 Top-N 组合照样好看。
2. **那个头部正是偏差最集中的地方。** 2017 年动量排前 5%、
   同时还留在今天榜单上的票，就是后来的巨头。策略"预测"到了它们，
   但池子本来就是按这个选的。

**年化超额 21%、最大回撤 15% 的股票策略在真实世界里极其罕见。**
先验上几乎一定是偏差。上面两条给出了具体机制。

### 一个被推翻的预判

开发中曾预判：「若 60 日持有的组合掉到接近 0，说明 +240% 来自持有期
与验收口径不一致」。**实际结果相反**——60 日持有 +379.95%，比 21 日更高。

口径不一致（已修）不是主因，信号衰减慢而不是快。记录于此，
因为事后重写预判是研究诚信最常见的失守点。

## 4. 因子层面确实学到的东西

这些**不构成可交易结论**（没过显著性线），但作为下一轮的假设有价值：

| 发现 | 证据强度 |
|---|---|
| 四个风险因子（低波动/低回撤/低下行/低尾部）三段同负且单调加深 | 方向一致性强，但单个 \|t\| ≤ 2.2，未过校正线 |
| 四个动量因子三段符号翻转，段 2（2020-07~2023-05）集体崩溃 | 模式高度一致；该段正是疫苗行情风格急转 + 2022 熊市 |
| 全期动量 IC ≈ 0 是段 2（−0.060）与段 1/3（+0.027）平均的结果 | 不是「动量无效」，是被中间段抵消 |
| 近 1 月反转是唯一三段同正的因子 | 量级极小（IC +0.011，t +0.8） |

**风险因子那条的可能解释**：股票池全是超大盘，低波动 ≈ 公用事业/必需消费/保险，
高波动 ≈ 科技巨头。2017–2026 是科技巨头碾压的九年。所以这更可能是
「波动率在超大盘子集里成了『是不是科技股』的代理变量」，
而不是低波动异象本身失效。

## 5. 已经建成、且与结论无关的基础设施

这些无论下一步走哪条路都继续有效：

- 未来函数守卫（篡改 t 之后的数据，t 时刻因子值必须不变）
- 行情粒度校验（Yahoo 会静默把日线降级成月线，已实际拦下过一次事故）
- 缺失语义（不知道 ≠ 中性，绝不用中位数填充）
- Newey–West 修正的重叠窗口 IC + 独立窗口数
- 逐因子 IC 分解 + 子区间稳定性
- 多重检验校正 + 尝试台账（阈值随尝试次数收紧，只增不改）
- 幸存者偏差暴露度
- 自包含 HTML 报告
- 80 项离线自检，含端到端双向验证（有信号必须找到，纯噪声必须找不到）

## 6. 下一步的三条路

### A. 修股票池（唯一能真正解决问题的）

用 point-in-time 成分股替换「今日市值榜」。
免费可行路径：维基百科的 S&P 500 成分变更历史带日期，
可从今天的名单往回推重建近似的历史成分。

- 修掉：幸存者偏差 + 前视选择偏差
- 工作量：中等
- 风险：变更记录越早越不完整

### B. 换一个天然没有横截面选择偏差的问题

例如**择时**（判断市场整体方向）而不是选股：只需要 SPY 一条序列，
不存在「哪些股票进池子」的问题，幸存者偏差从定义上就不存在。

2514 个交易日、前瞻 20 日 → 约 125 个独立窗口，功效远好于选股。

### C. 改变模型定位，立即可用

Alpha 60 的 `scan` 已经能每天把 371 只压缩到 20–30 只值得读财报的标的。
**这个功能不需要 alpha 就成立**——它声称的是「按统一规则排序」，
不是「预测收益」。

前提是输出里必须继续如实写明：分数是横截面排序，不是收益预测；
回测未能证明预测能力。
