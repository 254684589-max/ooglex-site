# Nasdaq-100 单一企业 5Y CDS 研究 V1
## 本期范围
- `macro/nasdaq100-cds.html`：独立信用风险研究页面，复用资产罗盘样式。
- `macro/nasdaq100-cds.json`：100家企业/101只股票的研究快照；2026-10-22名单与2026-11-23 QQQ持仓交叉检查，QQQ不是正式指数数据授权源。Alphabet合并。未获得正式实时成分授权，不声称实时官方名单。
- `macro/nasdaq100-cds.js`：名单、搜索、企业历史占位和关闭门禁；任意非空行情、历史或未经核验的映射导致页面拒绝数据。
- 总览及宏观指标中心增加入口，不修改资产评分逻辑。
## 合约准入目标
USD、优先债务、单一参考实体、5年期标准 CDS、等价平价利差 bps。未来需补齐参考实体 RED/LEI 或官方产品标识、币种、重组条款、优先级、交易起息/到期、有效日期、价格类型与单位、原始记录ID、来源时间、修订及取消状态。股票代码不是参考实体证明。ICE 结算价格不是直接的利差。
