# Ooglex AI金融终端：项目简报

> 状态：规划阶段  
> 建议入口：`/apps/finance-terminal/`  
> 中文名称：Ooglex金融终端  
> 英文名称：Ooglex Finance Terminal

## 1. 项目背景

Ooglex 已拥有宏观雷达、全球资产表现、公司市值、金融风险、经济日历、财经新闻、超级投资者等独立数据应用，并通过 Python 与 GitHub Actions 自动生成静态 `data.json`。

下一阶段不推倒重建，也不重复开发现有数据管道，而是把这些能力整合为统一、可信、适合中文用户的金融研究入口。

## 2. 产品定位

Ooglex AI金融终端是一款面向中文个人投资者的跨资产研究工具。它以“数据来源透明、更新时间明确、解释通俗、移动端可用”为核心，将分散的市场数据组织成一套可连续使用的研究工作台。

它不是交易执行软件，不连接券商下单，也不承诺提供交易所级实时行情。

## 3. 目标用户

- 关注美股、全球资产和宏观经济的个人投资者
- 希望用中文理解利率、流动性、信用和市场风险的学习者
- 需要快速查看公司、资产、新闻、经济日历和机构持仓的研究者
- 主要使用手机，同时需要电脑大屏研究体验的用户

## 4. 用户核心问题

1. 市场目前处于什么宏观和风险环境？
2. 股票、债券、黄金、美元、原油和加密资产谁强谁弱？
3. 当前数据是什么时间、什么频率、来自哪里？
4. 今天有哪些重要经济事件和市场新闻？
5. 哪些公司、资产和机构持仓值得进一步研究？
6. 数据过期、来源失败或仅为模拟数据时，页面能否明确提示？

## 5. 产品原则

- **可信优先于炫技**：不伪造行情，不隐藏数据延迟。
- **整合优先于重写**：优先复用现有应用和数据文件。
- **中文优先，术语双语**：中文界面为主，关键金融术语保留英文。
- **移动端优先兼容**：手机可完整使用，电脑提供更高信息密度。
- **渐进式架构**：第一阶段保持静态站点，确有需求后再引入 Workers、D1 和 R2。
- **低成本可持续**：控制外部API、AI调用和后台任务成本。
- **非投资建议**：所有页面必须保留研究用途和风险提示。

## 6. 第一阶段核心功能

第一阶段只建立统一终端，不新增收费数据源：

1. 全球市场行情条
2. 宏观状态与综合风险分
3. 跨资产涨跌与强弱排行
4. 股票、债券、黄金、美元、原油、比特币概览
5. 恐慌贪婪与OFR金融风险
6. 今日经济日历
7. 最新财经新闻
8. 全球公司领涨、领跌与市值排行
9. 全站统一的数据来源、数据日期、更新时间、频率和过期状态
10. 手机与电脑自适应布局
11. 数据加载失败、部分缺失和过期状态
12. 快速进入现有详细应用的导航

## 7. 后续能力

第一阶段稳定后再评估：

- AI市场解释与基于站内数据的研究问答
- 自选股和观察清单

## 9. 数据可信标准

终端展示的每组金融数据必须尽可能包含：

- 数据来源及可核验链接
- 数据对应日期 `asOf`
- 文件或接口更新时间 `updatedAt`
- 更新频率：实时、延迟、日频、周频、月频、季频或年度
- 数据状态：正常、延迟、过期、部分缺失、模拟
- 必要的方法说明和代理指标说明

只有数据供应方明确提供实时数据，并且页面实际按相应频率刷新时，才可以标注“实时”。

模拟数据必须带 `demo: true` 或等价的机器可识别字段，并在界面显著显示“模拟数据”或“演示数据”。

## 10. 非目标

第一阶段不做以下事情：

- 不连接券商或执行交易
- 不迁移、重命名或删除现有栏目
- 不承诺交易所级实时行情
- 不创建用户账号系统
- 不接入未经确认的数据付费方案
- 不把AI生成内容当作事实或行情来源
- 不直接迁移主站至Cloudflare Pages
- 不部署到生产环境，除非项目所有者明确批准

## 11. 第一阶段成功标准

- 新终端可以独立访问，原有页面和链接不受影响
- 主要数据模块均能显示来源和更新时间
- 数据过期或加载失败时不会展示成正常实时状态
- 360px宽手机与常见桌面尺寸均可完整使用
- 页面无明显横向溢出和关键操作遮挡
- 不暴露API密钥，不在浏览器端保存站长密钥
- 相关检查通过，且提交中不含无关文件
- 未经批准不合并到生产分支、不部署生产站点
