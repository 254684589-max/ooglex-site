# Ooglex 全球资产罗盘｜V49 因子准入证据矩阵

## 产品交付
在 `/macro/overview.html` 的V48指标独立性审计之后、六资产卡片之前新增「V49 因子质量准入 · 历史证据门禁」表。覆盖全部14条源系列，逐项展示：
- 当前真实观测是否可用（沿用日频、周频、月频独立时效门禁）。
- 网站首次观察历史的不同观测期数，研究性覆盖参考线：日频252期、周频104期、月频36期（**参考线不是通过资产评分的充分条件**）。
- 官方首次发布时间的PIT证据是否认证；后续修订的全版本可追溯性是否认证。
- 与V48代数派生、共享统计调查、联储会计体系重叠信息的**独立增量信息**是否通过研究认证。
- 严格按时间切分的样本外、完整可投资资产总回报的检验是否通过。
- 当前模型是否有资格进入0–100正式打分。

## 真实审计依据
直接复用现有 `data/asset-compass-history-readiness.json` 和 `data/asset-compass-factor-observations.json`，不重新制造所谓官方历史首发记录，不依赖模拟新闻归档，不创建自动交易系统。

已发布准备度报告仅有21条网站**首次归档记录**；大多数系列只有1个不同观测期，若记录出现两次，也不等于完成了修订历史核证。明确标注原有`treasury_source_year_mismatch_rows`来源年份异常数量。另一方面，V42官方财政部JSON拥有多年的真实市场观测，但 `original_release_vintages_available=false`，不能取代每个历史投资决策时点真正可得的首发版本。

两个报告都声明未通过模型校准和PIT历史资格，V49只报告证据缺口，不凭借已接入指标给出主观假分数。源数据无法获取、报告格式不符、历史覆盖虚增或任何门禁不可核实，都不会解锁投资评分。

## 现有模型不可被绕过
V22私有PIT独立性审计和V33历史资格要求保持不变。V49是用户可见的研究准入**状态面板**，不是新的可交易模型。即使将历史样本量修改为10000，仍不能绕过官方PIT、修订核证、信息增量和样本外验证门禁。
