# 铁冠之争 THE IRON CROWN · 路线图与台账

> 这是台账：每推进一步，更新「当前状态」和对应步骤的状态。接手前先读本文件，再读 `.claude/skills/ironcrown/SKILL.md`。

## 目标（所有者，2026-09-27）

- 以《权力的游戏》为题开发一款**第一人称角色扮演游戏**；定名《铁冠之争》；**优先于《余烬陷落》开发**。
- 所有者发来一张参考截图（雾夜小镇、石板路、枯树、暖色窗光、冷蓝色调），用来说明想要的氛围。
  截图看起来是其他商业游戏的画面：只用来理解氛围，不复刻、不进仓库、不作 AI 生成的输入（`design/ART.md` 第一节）。

## 先说清楚的现实

| 维度 | 商业第一人称角色扮演游戏 | 本项目能做到的 |
|---|---|---|
| 团队 | 数十到数百人 | 所有者 + Claude；代码、玩法、剧情、着色器由 Claude 写 |
| 美术 | 专职建模、动捕 | **Claude 做不出 AAA 模型与动画**；靠 CC0 写实贴图（Poly Haven / ambientCG 可访问）+ 代码搭几何体 + 所有者提供或购买的素材 |
| 人物 | 精细的脸与表情 | 最大短板；先用代码搭的骨骼人形，垂直切片后决定升级方案（D4） |
| 引擎 | 原生客户端 | Godot 4.7 网页导出，只有兼容渲染器（WebGL 2）：没有体积雾、屏幕空间反射，本环境也无法烘焙光照 |
| 规模 | 大世界 | 小而密的手工区域：序章一个小镇，之后每章一个区域 |

结论：网页版能做到「雾、灯、写实地面与墙」撑起来的**氛围**，接近参考图的气质；人物精细度与动作是长期短板。
是否达标，在**阶段 3 垂直切片**结束时由所有者看实机画面决定。
