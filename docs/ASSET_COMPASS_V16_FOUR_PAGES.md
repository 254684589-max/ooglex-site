# Ooglex 全球资产罗盘 V16｜四页面研究终端

第十六阶段把原先单一长页面组织成四个可独立访问的研究页面，并保留所有原有宏观指标监控代码。

| 导航 | 静态路径 | 真实内容 |
|---|---|---|
| 全球资产总览 | `/macro/overview.html` | 六类资产发布状态、国债主要指标；未经独立校准的资产评分统一保留 `— / 100` |
| 宏观指标中心 | `/macro/`、`/macro/index.html` | 原先完整的利率、BLS、BEA、联储和纽约联储数据监控，以及日期与来源 |
| 资产因子归因 | `/macro/attribution.html` | 直接读取 `model-config.json` 中的六资产×六因子初始权重；展示已实现指标定义数量，**不声称真实因子贡献或完成模型校准** |
| 回测与预警 | `/macro/research.html` | 展示受保护构建中生成的价格覆盖审计和宏观首次归档准备度；历史收益、命中率、回撤、预警仍未获准发布 |

共享样式 `macro/compass-pages.css`，受限 JS 数据可视化 `macro/compass-pages.js`。页面独立工作，不依赖外部前端 CDN 或收费 API。未取得真实数据或内容审计时显示缺失，不以旧快照或示例数值替代。

## 核心安全边界

- **未公开任何经验证的六资产综合评分**：前端必须看到资产自身的校准和样本外验证标记才显示分数，且后端 `score_macro_assets.py` 继续采取无足够验证不输出策略分数的守卫。
- 因子归因页面现阶段是**权重和指标覆盖说明**，不是对黄金、美股等资产的已验证贡献分解。
- 历史行情覆盖率不是投资可用的总回报表现，上市/指数/期货报价许可和股息、期货展期等口径仍需审核；不发布未经回测的命中率、夏普率、最大回撤或评分变化告警。
- 工作日官方数据更新、原有宏观监控信息、Pro/Free 保护和游戏均不改动。
- 受保护网站构建自动核对四页面、JS、CSS 和数据定义配置文件都在 `.site/macro/`。实际自定义域名部署与缓存仍需独立核实。

## 第十七阶段后续

逐个补充合法数据源和历史时点信号，将各因子原始指标、方向和中间计算明细作为**不代表买卖信号**的研究内容展示；在真实完整校准通过前，不开放“黄金XX分”“预测涨跌”等正式结论。
