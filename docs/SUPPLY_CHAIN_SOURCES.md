# 全球供应链板块：数据源与许可规范

> 状态：**探测阶段**，尚无任何序列登记，尚无页面代码
> 建议入口：`/apps/supply-chain/`
> 中文名称：全球供应链　英文名称：Global Supply Chain

## 1. 本次结论

站内 33 个应用全部集中在「价格侧」——宏观雷达看利率与信用，商品看价格，公司看市值。
**没有任何一个覆盖「实物流动」**：船在不在走、港口堵不堵、咽喉通道通不通。供应链板块补的
就是这一层，且与既有栏目不重叠、不替代、不迁移。

本板块沿用全站既定边界：服务器端取数 → 生成静态 JSON → 页面读取；不调用第三方行情 API，
不宣称实时，不伪造数量数据，逐条标注来源、数据日、更新时间、频率与状态。

**关键判断：本领域最知名的几个指数全部是商业授权，技术上取得到不等于可以再发布。**
因此本板块把「许可」与「可取」列为同等准入条件，两项都过才允许登记。

## 2. 许可红线：不得接入的来源

与仓库已因许可放弃的 `SPX`、`NDX`、`DJIA`、ICE 美元指数、LBMA 定盘价属于同一类问题。

| 数据 | 权利方 | 结论 |
|---|---|---|
| 波罗的海干散货指数 BDI 及各分项 | Baltic Exchange | **不接入**。专有基准，再分发需授权 |
| Drewry World Container Index | Drewry | **不接入**。商业订阅 |
| Freightos Baltic Index FBX | Freightos | **不接入**。商业授权 |
| Xeneta XSI | Xeneta | **不接入**。商业订阅 |
| ISM 制造业 PMI 供应商交付分项 | ISM | **不接入**。已因许可自 FRED 下架 |
| ATA 卡车吨位指数 `TRUCKD11` | 美国卡车运输协会 | **不接入**。FRED 上存在但权利方为私营协会 |
| Cass 货运指数 `FRGSHPUSM649NCIS` | Cass Information Systems | **不接入**。同上 |

后两条**故意保留在探针清单里**：它们确实取得到，探针会以 `[!!]` 标出「取得到但不许登记」，
留证以防日后被误加回来。

不得用「先上线再申请许可」「只展示不再分发」「加了免责声明就可以」等方式绕过本节。

## 4. 探针要回答的问题

`scripts/supply-chain/probe_supply_chain_sources.py`（由 `Supply Chain Source Probe` 工作流运行）
逐条回答：

1. **取不取得到**——接口在 Actions 机房是否返回结构合法的数据；
2. **是不是还在更新**——末次观测日是哪天（取得到不等于还在更新）；
3. **许可能不能用**——逐条标 `GOV` / `IGO` / `PRIV`，`PRIV` 一律拦下；
4. **PortWatch 到底长什么样**——不写死 ArcGIS 服务 ID，先读站点 DCAT 开放数据目录列出
   真实存在的数据集，再探测相关图层的字段与日期字段。凭印象写死服务 ID 正是
   `scripts/probe_commodity_sources.py` 顶部记录的 `B0=F` 教训要避免的。
5. **GSCPI 数据文件是什么格式**——若为 xlsx，探针会确认它是不是标准 zip 容器；
   是则可用标准库 `zipfile` + `ElementTree` 解析，**不必新增依赖**（仓库规则不自动装依赖）。

探针只读，不写仓库任何数据文件，不改任何清单，密钥只从环境变量读取且绝不打印，
逐个候选独立 `try/except`，请求间留间隔，有全局请求上限。报告以 7 天构建产物留存，
不进入 Git 历史。

## 5. 降级方案

**若 PortWatch 探测不通过**（无可用图层、无日频字段或许可不明）：

- 通道层与枢纽层降级为月频/年频口径：世界银行集装箱吞吐量 + FRED 政府口径贸易与运输序列；
- 压力层（GSCPI）与投入层（站内商品）不受影响，仍可独立交付；
- 页面明确显示「本板块当前无日频通行量数据」，**不得用月频数据冒充日频，不得用估算值填充**。

降级版差异化显著减弱。是否在降级情况下继续推进，由项目所有者依据探针报告决定。

## 6. 数据真实性要求

沿用 `AGENTS.md` 与 `docs/PROJECT_BRIEF.md` 第 9 节，本板块另加两条：

1. **数量不是价格**。到港船舶数、通行艘次、吞吐量为数量口径，不得与价格混排、不得换算成
   「指数」后隐去原始口径。卫星 AIS 推断的数据必须标明为推断值。
2. **事件解读只能是规则摘要**。如「巴拿马运河 7 日均通行量较 90 日常态低 22%，处于近一年
   5% 分位」——由数据算出，可复算。**不得使用 AI 生成的事件叙述作为事实来源**，与金融终端
   「市场洞察仅是三项既有信号的规则摘要」同一边界。
