# SOFR V15｜真实历史数据可用性与合规回填试点（2026-11-23）

## 现实数据源
1. [CheckMySwap — USD SOFR OIS archived curves](https://www.checkmyswap.com/rates) 在网站上公开显示的归档起点为 **2026-03-19**，支持针对具体已有日期读取 `GET /api/curves/USD?date=YYYY-MM-DD`。缺失快照直接返回404，不允许回退最近日期。近端汇总数据属于指示性估计，不是可成交交易商报价。旧快照可能被后续重新计算，日期不是不可修改的原始版本证明。
2. [US Treasury official daily yield XML](https://home.treasury.gov/treasury-daily-interest-rate-xml-feed) 从1990年提供Daily Treasury Par Yield Curve Rates，可使用年份XML按日期获取2、3、5、7、10、30年CMT。
3. 两端的历史起点不同，因此若不另寻独立SOFR互换数据授权/重建，只能审查**2026-03-19起**的CheckMySwap原始日期。不能据Treasury历史长就声称已有十年互换历史。

## 许可门槛（关键）
CheckMySwap写明网页/curve explorer免费访问、提供下载，**但免费阅读或公开数据不等于允许Ooglex批量复制、长期保存和对第三方用户重新发布历史SOFR曲线及衍生价差**。本次未找到明确覆盖第三方站点批量转载的书面许可。合规状态：`not_obtained`，正式网站历史JSON不可修改。需要向权利方或原始数据提供者确认：商用/非商用网站呈现、衍生利差、批量存储、归档修订、署名与访问限额。

## 非发布数据质量试验
- `scripts/audit_sofr_backfill_pilot.py` 使用现有V6两源候选验证器，按实际日期抽样10天：2026-03-20、04-15、05-15、06-15、07-15、08-14、09-15、10-15、11-13、11-20。
- 数据检查：USD SOFR OIS日期与Treasury CMT必须完全一致、六期限齐全、固定利率为正、方法限定 `close/close-thin`、价差公式成立。若有任何派生 `derived` 或 `all-day` 期限，整日被拒绝，不能自动混入“收盘”样本。
- 生成的报告只包含日期、候选/未找到/被拒绝/历史冲突标记、合格期限数、稀疏收盘期限数、源响应SHA-256摘要。**不把历史SOFR原始价格/价差保存在仓库、PR、artifact、日志或网页中**。
- 如样本与现存2026-11-20归档不一致，记为 `archive_conflict` 并对CI标红，需检查历史快照修订；禁止直接覆盖现有真实数据。
- 本批次是**样本覆盖和方法一致性研究**，不是完整的约160个工作日/交易日回填，也不保证10个日期均存档。
- PR CI采样后上传7日元数据Artifact，以便核查候选个数、失败类型和首次可用日期。仓库正式历史 `macro/swap-spreads-history.json` 一律不变。

## 授权后才能批准生产回填
1. 获得可核查的回填/重分发许可范围及归档修订处理规则。
2. 批量候选对照完整美国交易日历；仅导入来源实际保存、六期限合格的同日两端报价；不以插值、重复、合成数据凑足历史。
3. 每个导入批次形成单独审查PR和源指纹清单，明确数据起点、有效样本数量、稀疏样本比例及异常。
4. 依据真实样本量阈值启用历史曲线/分位数；图表不能以一条数据强画趋势。
5. 首轮日更（2026-11-24）及网站公开访问分别验收，不与历史回填相互混淆。

V15专门做真实历史数据的**非发布抽样验证**，未进行版权许可判断或生产数据回填。网页现在只显示一天历史，属于真实覆盖不足。
