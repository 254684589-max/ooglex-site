## 真实PIT阻断

现有Ooglex历史归档大约14项宏观系列，首次归档时间是**Ooglex首次看见数据**，不是官方在当时公布的第一版本。工作流保留上游历史归档中财政部年份来源不一致的行数（当前审计基线为5），不通过静默删除历史、改时间戳或将first-seen冒充first-published消除缺口。

建立每个信号的如下独立证据才算PIT合格：
1. 观察期末日期 observation_date；
2. 官方公告发布时间 official_released_at（含时区及来源）；
3. 首版数据版本 original_vintage_id、原始文件摘要及修订链；
4. 策略在何时实际可见 available_at，严格不得早于公告时间、不得晚看早用；
5. 源采集时间 first_seen_by_ooglex，只作监测证明，**不作为官方历史first release的替代证据**。
