# Ooglex 全球资产罗盘｜V21 六资产专属因子证据体系

## 本阶段定位
建立六类资产各自的资金流、持仓、需求、估值代理指标的**候选目录与受控证据准入程序**。这不是自动联网采集器，不意味着取得商业授权、官方历史首次发布存档或完成因子预测校准。V21 不修改 `macro/model-config.json`、正式评分程序及网站四页面。

## 候选资产映射（每项均待独立可用性及权利核验）
| 资产 | 候选指标 | 说明与重要限制 |
|---|---|---|
| 黄金 | CFTC 黄金期货持仓 | 期货参与者仓位，不是全部黄金资金流 |
| 黄金 | 黄金 ETF 持仓吨数 | 需要确认 WGC/供应商口径和再分发授权；持仓变化不等于全部净流量 |
| 美股 | SEC 13F 披露持仓 | 季度披露、存在报告滞后，不代表实时机构流向 |
| 美股 | SEC 公司利润报表 | 只是估值输入；不能直接等同指数整体 PE |
| 长期国债 | Treasury 拍卖投标倍数 | 单次拍卖供需，不等于完整二级市场资金流 |
| 长期国债 | Treasury 拍卖间接竞标比例 | 单次拍卖买方结构，并非所有长期国债持仓 |
| 美元 | CFTC 美元指数期货持仓 | 期货仓位，不等于全球美元净流动 |
| 美元 | BIS 有效汇率指数 | 汇率水平代理，不是美元内在估值或资金流 |
| 比特币 | 链上流通供给估计 | 必须核对统计口径；不是交易所可售供给 |
| 比特币 | BTC ETF 净流量候选 | SEC 基金披露可能可用于验证部分数据，但不能直接产生逐日 ETF 净流量 |
| 原油 | EIA 美国商业原油库存 | 库存水平不是期货净持仓或即时油价方向 |
| 原油 | CFTC WTI 原油期货持仓 | 按周报告的持仓代理，覆盖范围和滞后需要核对 |

## 技术文件
- `scripts/asset_compass_asset_specific_v21.py`: 12项候选目录、来源域名/指标单位/资产ID/可审查权利凭证及 as-of 校验，输出六资产研究证据覆盖报告。
- `tests/test_asset_compass_asset_specific_v21.py`: 8组离线合成测试，覆盖六资产映射、权利拒绝、未来发布时间隔离、来源假冒、缺失、零和负数、重复版本和正式评分锁。
- 不访问网络、不采集第三方数据、不发布原始数值；输入 JSON 必须位于公开仓库之外。

## 私有输入格式
JSON 数组，每条记录须包含：`indicator_id`、`asset_id`、`observation_date`、`available_at`（带时区）、`value`（JSON数值）、`unit`、`source_url`（对应官方/供应方证据的HTTPS链接）、`source_release_id`、`rights_evidence`、`research_use_approved`。

`rights_evidence` 和 `research_use_approved` 只是操作员的研究用途声明，**无法自动判断合同真伪或许可范围**。真实发布时刻不明时不得编造。仅对 source host 进行结构校验不等于确认具体链接指向可复核的数据版次。

## 操作示例
```bash
python3 -m unittest tests.test_asset_compass_asset_specific_v21 -v
python3 -m scripts.asset_compass_asset_specific_v21 --input /tmp/verified-private-asset-evidence.json --asof 2026-11-20T12:00:00Z
```

没有真实数据则应直接报错；输入为空数组仅代表无证据，不得解释为中性。

## 验收边界
- 只有经过权利和发布时间审核的真实资料才有资格进入私有历史证据库；模型尚未形成历史因子信号。
- 各候选数据不能未经频率/口径/去重/统计独立性审核就加权合成。
- 不输出收益预估、排名、买卖建议、0–100正式分数或自动预警。
- V21 依赖 V20、V19、V18 的逐阶段验收，未完成前不合并 main。
