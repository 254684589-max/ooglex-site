# Ooglex 全球资产罗盘 V44｜精确历史读数与两点基点变化

## 目标
在 V43 官方收益率双曲线的基础上，让用户能够读出某个**真实观测日**的数值，并选择两个实际交易/观测日比较该期间的利率变化。本阶段不新增历史源、不构建评分、不生成新闻稿。

## 已实现
- 鼠标/触摸指针移动到 SVG 时，按当前展示范围对应的真实观察记录定位，显示原始历史观测日期、主曲线及可选第二曲线的数值。不会把无发布值的周末补作观测；键盘聚焦图表时显示最后观测点。
- 图下方起点/终点下拉菜单仅包含图表当前范围内 **实际存在** 的同日配对历史观测日期。默认从可见范围最早日到最晚日；切换不同曲线时，若仍在该日期范围内则保存用户所选日期。
- 按真实数值计算变化：`终点收益率 − 起点收益率`，分别显示百分点（pp）与基点（bp；1pp=100bp）。如果显示两条曲线，分别计算两者的bp变化；**不**使用收益率变化冒充债券价格或资产投资回报。
- 不允许终点早于起点，日期不在历史 JSON、图表缺失或数据未通过 V42 来源和数学检查时，不会推断、插值或虚构点。
- 复用 `data/asset-compass-treasury-history.json`，来源和真实观测日期由既有质量门禁验证；目前实际官方财政部数据为1,472个同日配对观测日（2021-01-04 至 2026-11-20），未来更新记录数会自然增长。
- 两点比较是宏观债券市场的**绝对收益率变化**，没有资产权重、估值、投资方向或历史PIT验证。正式六资产0–100评分、投资组合回测与自动投资提示仍锁定。
