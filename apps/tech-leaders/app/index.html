安装步骤

  1. 用手机浏览器打开本页，点「下载安装包」。
  2. 下载完成后点开安装包。如果提示「禁止安装未知来源应用」，按提示在设置里允许当前浏览器安装应用。
  3. 部分手机（华为、小米、OPPO、vivo 等）会提示「外部来源应用」或进行安全扫描，选择继续安装即可。
  4. 安装后桌面会出现「OOGLE X」图标，打开后输入访问密码。已装旧版的直接覆盖安装即可，名字和图标会自动更新（部分手机需重启桌面后才刷新图标）。

说明

  • 应用内显示的就是 ooglex.com 上的专栏，内容与网页版同步更新，无需为内容更新重新安装。
  • X 原帖、新闻原文等外部链接会用手机浏览器或对应应用打开。
  • 应用不读取通讯录、位置、相册等权限，只需要联网。

安装包由 GitHub Actions 从本站公开源码自动构建，可用上方 SHA-256 核对文件是否完整。
