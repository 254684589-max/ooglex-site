三个方案

三个方案都读各应用现有的 data.json，16 个入口和链接不变，只改版式。正式页面 /apps/data-hub/ 没有改动。

方案 A · 仪表头条

顶部通栏大卡：半圆仪表 + 前收/一周/一月/一年对比 + 七项分项条 + 一年走势。下面四类统一成三列小卡，每张一个大数字。

打开方案 A → 方案 B · 情绪色带

头条整块按当前情绪着色，超大数字 + 0–100 五档色带。紧贴下方一排「风险四联」（宏观风险、金融压力、AAII、经济日历）。其余三类做成报纸式数字墙，无卡片、细线分隔。

打开方案 B → 方案 C · 终端双栏

左栏深色固定面板放恐慌贪婪（环形读数、历史对比、分项刻度、走势），滚动时一直可见。右栏按四类排成行情表：名称 / 主读数 / 补充 / 频率与更新时间。
